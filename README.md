# 笔记狼人杀

房主可在已结束对局选择「再来一局」：先可靠归档，再复用房间号、玩家和座位进入下一局候场；所有人重新准备和确认身份。我的记录与收藏按局独立访问，旧笔记、版本和有效分享保持原权限。完整[范围与兼容](docs/WEREWOLF_RULES_SPEC.md#rematch-2026-10-20)及[验证记录](docs/TEST_REPORT.md)分开；生产持久化/备份和实机验收仍待完成。

手机优先的线下面杀辅助 Web App。当前支持房间、座位、准备、私密发牌及完整自动对局，可跨多夜、多天运行至胜负结束；支持独立手动记录、多版本复盘、账号、基础后台、用户收藏及 VIP 只读分享。

## 手机使用

电脑安装 Node.js **24 或更新版本**，运行：

```bash
npm ci
npm run dev
```

本地需要模拟玩家和测试控制台时运行 `npm run dev:test`，并登录管理员账号；普通 `npm run dev` 不启用测试入口。生产默认关闭，仅保留已授权 Render 试用服务的显式例外，当前线上未启用。

macOS 的 `npm run dev` 会在服务端代码或契约更新后自动重启。其他不支持 Node `--watch-path` 的平台可运行 `npm run dev:once`，代码更新后手动重启。若此前已开着旧版开发服务，请在原终端停止后重新运行一次；保留 `.data/lobby.db`，无需清除浏览器或数据库。

电脑访问 http://localhost:3000 。手机与电脑连接同一局域网，打开 `http://电脑局域网IP:3000`；服务监听 `0.0.0.0`。macOS 可用 `ipconfig getifaddr en0` 查询 Wi-Fi 地址，防火墙需允许 3000 端口。电脑需要保持服务运行。

每部手机或独立浏览器配置有独立游客身份；同一浏览器的多个标签共享身份，不能作为两名玩家。普通 HTTP 局域网下剪贴板可能受浏览器限制，可手动复制显示的房间号。真实 iPhone Safari 尚未验收。

候场和对局中的“规则”可打开本局角色目录与特殊机制速查，普通游客也可用；目录只展示公开配置，不列任何座位的身份或实际技能次数。白天“我的身份与技能”保留本人真实余量并可展开技能限制。开关不暂停或重置对局，未知规则/自定义交互明确提示需裁决。详见[规则速查](docs/WEREWOLF_RULES_SPEC.md#rule-reference-2026-10-20)，本地实现、未部署。

## 主屏幕安装与恢复

本地已实现PWA安装元信息与按需说明。部署到HTTPS后，iPhone Safari可从首页「添加到主屏幕」查看操作步骤；普通局域网HTTP开发服务不注册Worker。Worker仅缓存固定公开静态资源，断网显示「目前无法联机」，对局和记录仍需联网授权。

离开页面或断网前请保存编辑：恢复时会清除未保存表单，重新核对当前账号、房间或分享权限；已保存服务器草稿保留。新版本就绪后，请先保存笔记，关闭本站所有窗口再重新打开。完整[恢复与缓存边界](docs/WEREWOLF_RULES_SPEC.md#pwa-2026-10-20)及[实际验证](docs/TEST_REPORT.md)分开；本批未部署，真实iPhone安装、锁屏、弱网和VoiceOver待验收。

## 准备与发牌

1. 输入昵称创建房间，或输入四位房间号加入；支持前导零、完整粘贴、自动跳格和退格。
2. 玩家自行选座，**房主必须占座参赛**。发牌前可改选空位或取消入座；发牌后锁定座位。
3. 房主分别选择发牌方式（线上随机 / 实体牌录入）和游戏模式（自动法官 / 纯手动记录）。四种组合均支持准备与身份锁定。
4. 房主可选择标准12人、机械狼通灵师、机械装甲模板，或保存自定义人数/角色配置。配置人数全部入座并准备后开始发牌。自定义调整使用角色标签：普通狼人/村民可用加减按钮，其他标签点击加入1名、再次点击移除，人数自动求和；白痴规则只在选中白痴时显示。旧保存/API配置中的重复黑/白狼王继续兼容，允许0普通狼人。改变配置会清除全员准备；改变座位会清除本人准备。旧配置下延迟的准备请求不会生效。
5. 线上牌由服务器随机分配，每人私下查看并确认自己的身份。实体牌由本人秘密录入；全部提交后由服务器核对角色数量。数量不匹配时全员看到统一检查提醒，不展示错误者或角色差额。
6. 全部身份确认且数量与配置一致后，房主开始对局，身份锁定。自动模式可继续进入首夜与第一天。当前服务输入容量为1–256席，不代表任意人数组合都已有完整规则。

只有夜间导航可「开启播报」，白天全部静音且隐藏语音入口；进入白天自动停止并释放播报。入夜首角色之前说「天黑请闭眼」，后续狼人行动不重复。默认使用已预录的系统中文语音，同设备可缓存复用，未使用实时外部生成服务；管理页可重播当前提示。13–15席末行卡片已与其他行等高，房主仍须确认本人身份。狼刀权限确认为15秒，其后闭眼缓冲仍为5秒。

自定义配置已支持黑狼王、白狼王及机械/装甲复制，独立次数、真实狼阵营、共享狼刀；黑枪与白带人先判胜，吞毒自爆不带人。完整时点与限制见[狼王规则](docs/WEREWOLF_RULES_SPEC.md#wolf-kings-2026-10-12)。本地验证不代表公网部署或真实iPhone验收。

14人且含一名白痴的自定义配置可在「自定义调整 → 白痴规则」主动选择双边变体；默认不启用。翻牌后神边出局、民边仍存活，禁发言/插嘴/投票/再次放逐，仍可被刀或毒杀。无任何狼角色仅可用纯手动记录，由房主确认「结束记录」，不判胜负，结束后可发布；只有狼角色的配置不能正常开局。仅缺神或仅缺民、零普通狼但有机械/装甲狼的配置继续允许。

身份默认隐藏，页面切到后台时同步隐藏并卸载业务界面，回前台重新校权后再显示。服务器限制每人只读取或提交自己的身份；普通房主不拥有他人的身份读取或夜间代操作权限。公共实时消息不含身份。

首页「我的记录」可管理本人记录，包括已清理实时房间的记录；局内「记录」也可点「永久删除我的记录」。再次确认后删除私人草稿及全部本人发布版本、使关联分享失效；官方事实、其他作者版本与对局评论保留，无法恢复。VIP到期仍可删除本人记录。删除后有记录资格者可主动「新建记录」，旧链接不会恢复。完整边界见[永久删除规则](docs/WEREWOLF_RULES_SPEC.md#personal-record-deletion-2026-10-14)。

## 首夜操作

以下段落描述标准预女猎白。机械／装甲局按配置增加混血儿首夜榜样、入夜刀权提示、守卫、固定机械狼／装甲狼及通灵师阶段；本人私密操作学习、技能和查看结果，机械阶段不会因拟态、死亡或技能耗尽改变公开顺序。学习及库存跨夜保存，未知规则组合明确停在待裁决状态。混血儿白天仅本人查看榜样座位；12人3民1混变体与扩展板使用各自已确认的屠民条件。完整规则、待决交互及验收证据见[机械阶段进度](docs/MECHANICAL_IMPLEMENTATION_PROGRESS.md)。

普通玩家入座后只需准备一次，不再重复确认手机就绪。自动模式开局后，房主点「开始首夜」直接进入狼人阶段；旧房间等待页由房主点「开始夜晚」。身份确认和夜间技能仍由本人操作。默认尝试保持屏幕常亮，浏览器不支持时如实显示不可用。

狼人投票（最多 180 秒）→闭眼 5 秒→女巫（首夜最多 60 秒，第二夜起最多 30 秒）→闭眼 5 秒→预言家（30 秒）→闭眼 5 秒→猎人查看状态（30 秒）。指定狼人可提前确认狼队刀口；女巫确认救人、用毒或不用药后立即进入 5 秒闭眼间隔。预言家查验后显示结果，再点「结束操作」；猎人确认已查看技能状态后提前结束。刷新不重置计时，切换后台隐藏秘密操作。前台当前阶段内保留未确认选项；切后台、断网或整页刷新后重新读取已提交记录，未提交选择清除。

首夜操作区按手机动态视口布局，显示阶段、倒计时、目标座位和动作。本人阶段自动显示技能，其他阶段显示等待；查验结果需点「结束操作」后继续。普通房主不能查看或代操作其他真实玩家。首夜结束由房主开始第一天，先竞选警长，再公布首夜死讯并判胜。药剂与死亡状态持续到后续夜晚，已死亡角色仍保留虚拟行动窗口。已开放暂停、恢复、神职重连宽限与公共语音播报。

## 测试玩家

开发环境可运行 `npm run dev:test`。先登录管理员账号，创建只有本人的新房间并入座，再点「补满测试玩家」。游客和普通账号即使是房主也没有测试入口。转换为测试房后，其他真人无法加入或订阅。你本人准备后即可发牌；「测试控制台」可切换当前配置的座位，操作准备、查看和确认身份。模拟玩家自动准备及确认。测试房间仅支持线上发牌，带有明确标签；控制台不能访问真实玩家的身份。开局后可进入首夜，在单屏操作区切换模拟角色；「推进测试阶段」用于跳过测试计时。

### VIP 收藏管理

有效 VIP 可在“我的收藏”搜索名称、房间号和有权读取的已发布内容，组合板子、作者、收藏日期筛选，并按收藏日期正序或倒序排列。自定义名称仅本人可见，留空恢复默认名称；不同设备编辑冲突时，可读取最新名称并保留自己的输入再保存。普通账号保留基础查看、取消收藏与时间倒序；VIP 到期保留已有名称，但不能继续高级查询或改名。

现有完整对局快照、参赛者复盘和外部分享收藏共用此管理面板；撤回内容不参与正文搜索，打开时仍按原权限检查。旧档案缺少板子信息时显示“板子未记录”。外部读者可在有效分享页登录/注册后收藏，无需VIP；首页打开仍检查收藏时的原链接。链接暂停/撤回/撤销或重生成后，收藏保留但不可读；恢复同一链接可继续读取，取得新链接后需自行重新收藏，旧名称/日期不自动迁移。匿名只读不创建Cookie；登录只在主动操作时开始。实现及验证边界见 [当前验证](docs/TEST_REPORT.md)。

### 第一天与测试自动跟随

首夜结束后房主点击「开始第一天」：警长报名、发言与退水、竞选投票/PK、首夜死讯、死亡技能与遗言、警徽移交、白天顺序/自由发言、放逐与 PK。统一技能询问 10 秒，发言/遗言 90 秒；投票默认 30 秒，可由房主在每轮开始前选择方式、时长和公开程度。猎人实际目标由房主按线下决定录入。胜负确定立即结束；未结束则由房主开始下一夜，循环至胜负结束。

开发测试房间默认「自动跟随」：首夜切到指定狼确认者及对应神职，白天依次切到报名、发言、投票和死亡技能玩家，并展示对应操作。可关闭后手动选择。此功能仅管理模拟玩家与房主本人；不授予代操作真实玩家的权限。允许环境内持有独立测试房的管理员每分钟 1000 个请求；普通会话及未启用例外的生产环境仍为 300 个。

### 完整对局与测试身份

管理员在独立测试房可看见模拟玩家角色，本人身份由原私人身份接口读取，座位和测试选择器显示相应角色。模拟身份接口只返回机器人，真实玩家身份不进入该接口或公共广播；生产默认关闭，限定试用例外见上文。最后一名留警者立即当选，结束剩余警上发言并公布死讯。普通自爆狼的优先指刀仅在紧接下一夜生效，吞毒狼无指刀权。

房主可选择手机操作或自由发言；手机操作显示警左/警右；当夜单死时显示死左/死右，可明确指定起始号码。按钮同时显示起始号码，递增/递减方向可核对。自由发言由房主控制整段结束，无逐人倒计时。结束后参赛者可查看完整自动记录、全部身份并收藏本局记录；未参赛访客不能读取记录。


### 最新规则与操作调整（2026-10-10）

第二夜起女巫、预言家、猎人操作上限均为 30 秒，死亡角色也保留相同虚拟窗口。技能目标必须仍存活，客户端禁选且服务端拒绝死亡目标。女巫确认立即进入闭眼间隔，操作结果仅本人高亮查看。

首次警上自爆后的竞选保留原报名、退水和 PK 候选人；次日直接进入退水 / 自爆，不重新报名或重复发言，再进入投票。此前已经公开死亡的候选人被排除；仅剩一名则自动当选。未公布的新夜死讯仍不能提前取消参选资格。PK 候选人自爆、二次中断失徽沿用已确认规则。

投票设置提供“开始手机投票”和“线下举手”两个按钮。线下举手不自动计时结束，由房主录入候选人总票数、确认后公布结果；不生成没有录入的个人票型。警长放逐票按 1.5 票，总票数与资格由服务端校验。

最新验证与截图见 [规则和界面调整报告](docs/GAME_RULES_UPDATE_TEST_REPORT.md)。

### 复盘和收藏

赛后记录按每晚、每天归纳实际操作和结果，隐藏阶段 / 指令流水；同一目标的投票者合并显示，只列有效票数。赛后“收藏本局”保存在服务器的当前用户收藏，首页“我的收藏”可查看 / 取消；刷新和服务重启保持，不下载 JSON。游客收藏与当前游客凭证关联，后续登录接到账号。仅参赛者可以收藏已结束对局，其他用户不能查看他人的私人收藏。

### 账号与后台（本地首版）

首页右上角可注册 / 登录用户名密码账号，游客仍可直接参赛。注册或登录关联本设备已验证的房间与收藏，同账号跨设备恢复相同玩家与座位，并撤销旧设备的秘密读取、操作和实时连接权限；密码错误或同房间已占不同座位时拒绝关联，保留双方状态。退出登录会恢复新的游客身份。收藏保存在服务器，账号收藏可跨设备读取。

执行 `npm run admin:create` 创建唯一管理员。随机初始密码保存在本地 `.data/admin-credentials.txt`（不提交 Git），用该账号登录后进入“后台”。后台查看 / 禁用恢复用户、查看公开房间状态及已结束对局记录；进行中的身份和秘密行动不会向后台开放。也可在首次启动前设置 `WOLF_ADMIN_USERNAME` / `WOLF_ADMIN_PASSWORD`，已有管理员不会被覆盖。后台另可开通永久或限时 VIP、取消 VIP，并只读查看已结束、已发布的复盘版本。点击右上角昵称 → “编辑资料”可修改昵称、预览/更换/删除头像。支持 JPEG/PNG/WebP，普通最多1MB、有效VIP最多2MB；资料修改保留座位、准备与私密身份。评论/通知已本地接入；支付尚未开放，最新功能未部署。

技能在本人阶段自动显示，无需“查看操作”；预言家查验结果后点“结束操作”，女巫确认和猎人确认已查看后提前结束阶段，角色间闭眼 5 秒。线下举手可选“几号投几号”或总票数，逐人票型由房主统一提交，弃票要显式选择。板子在创建后设置，当前范围见上方准备与发牌和机械阶段进度。

本轮验证见 [账号与最新手机交互测试报告](docs/AUTH_ADMIN_TEST_REPORT.md)。


## 暂停与重连

对局导航中的「管理」支持二次确认暂停、恢复和临时房主授权。暂停冻结所有倒计时与操作；恢复后全员准备 5 秒，再按原剩余时间继续。原房主死亡后仍可管理，临时房主必须存活，且没有其他玩家的秘密权限。

普通断线不会暂停游戏；多标签仅最后连接关闭才视为离线。尚未提交技能的存活神职每人每局最多获得一次 15 秒宽限；狼人仍严格限制在 180 秒。暂停期间可保存未来投票默认值，当前投票设置不受影响。详见 [暂停、临时房主与重连测试报告](docs/PAUSE_RECONNECT_TEST_REPORT.md)。

## 公共语音

自动夜间，房主、有效临时房主或当前法官可开启公共播报。一间房由一个标签播放夜间公开睁闭眼/角色阶段提示，白天全部静音；不会播报秘密身份、刀口、药剂或查验结果。纯手动模式没有自动播报。

保持该页面在前台。切到后台、断线、失去管理权限或切换纯手动会停止播报；刷新后需重新开启。已派发的历史提示不重复补播，可点「重播当前提示」。语音失败会提示，不影响对局计时。默认使用预录公共中文片段，保留浏览器语音替代选项；真实 iPhone 的声音、音量和播放限制仍待验收。详见 [公共语音测试报告](docs/PUBLIC_VOICE_TEST_REPORT.md)。


## 复盘评论与审核

打开已发布的复盘版本、有效分享页或分享收藏，点击“查看评论”。同一局所有作者/版本共用评论区，支持多级回复/折叠、分页及最新/最热/最早排序。匿名分享只读，主动登录后普通账号可评论、点赞或举报。发布后作者不能修改/删除；对局赞每账号按洛杉矶自然日限一次，评论赞永久限一次，均不能取消。

后台“评论审核”处理举报，删除父评论保留子回复；“用户管理→评论权限”可警告、限时/永久禁评及解除，均有原因与审计。禁评不影响正常游戏。顶部“通知”看本人处罚和账号/VIP消息，“我的账号”保留当前禁评状态。链接失效、VIP暂停/作者撤回后评论也不可借ID绕过权限。完整条件见[规则](docs/WEREWOLF_RULES_SPEC.md#community-2026-10-14)。通知中心及实际30天清理已接入，详见下节；评论30秒刷新会收起回复/分页但保留输入。本批未部署/未完成实机验收。

## 临时法官与切回自动

房主在局中点击“法官设置”，选择已公开死亡且死亡技能已处理完的玩家；手动局须明确确认线下处理完成。法官本人打开“法官面板”，可查看本局身份、秘密技能历史及库存，不能读玩家私人笔记，也不能继续玩家插嘴/投票/自爆或秘密行动；可管理公开流程。撤销或旧会话失效立即拒绝，后台/断线隐藏秘密，回前台需主动查看。

手动局法官点击“开始补录”，按现场发生的操作补齐，先核对官方事实、阶段与库存，再“核对并切回自动”。原自动操作保留，纯手动从首夜重建；冲突/未决规则阻断。切回先暂停，恢复准备5秒后当前阶段重新完整计时，已完成技能/票型不重做。无狼记录和已结束局不能恢复。原记录/私稿/修订保留。完整条件见[现行规则](docs/WEREWOLF_RULES_SPEC.md#judge-and-automatic-return-2026-10-13)与[验证报告](docs/TEST_REPORT.md)，尚未部署或实机验收。

## 独立记录与版本收藏

准备时选择「纯手动记录」，完成原有发牌与确认即可开始；自动游戏也可通过导航「记录」由房主二次确认切换。切换保留已锁定身份与自动历史，导入已公开死讯，停止自动计时和技能。手动切回由显式任命的临时法官补录核对，详见上节。

纯手动主屏显示座位、官方死讯 / 胜负和记录入口，保持手机一屏。房主与有效 VIP 参赛者各有自己的私密草稿，可记录死亡轮次及死因、警徽、放逐、几号投几号和个人推理。缺失事实显示「未记录」，不会推测或补执行技能。编辑弹窗关闭前提示保存 / 放弃，草稿版本冲突会拒绝覆盖。

只有房主提交官方死讯才更新公共状态并按 12 人预女猎白判胜。VIP 可申请结束，由房主审阅事实并明确采纳 / 拒绝；申请不分享个人推理，也不自动结束。房主失联时保持待确认。赛后可修正官方记录并保留完整修订；完整官方修订仅房主可见。修正后不满足胜负时显示「未达成胜负」，不重启已结束游戏。

赛后作者主动发布形成不可变历史版本，参局玩家可看全部身份与已发布历史。编辑草稿不会改变已发布内容；收藏关联版本帖子，跟随作者主动发布的最新版本。撤回后收藏入口保留、正文及历史暂不可读，再发布后恢复。旧自动记录收藏继续保留原始快照。

记录、发布历史和收藏独立保存在服务器，即使活动房间删除也保留；游客绑定账号后迁移其记录和收藏。后台不读取个人草稿和未发布官方修订，也不能绕过撤回。VIP 到期 / 取消后保留本人的草稿读取和撤回权限，停止编辑、发布及结束申请。

验证、真实设备限制及数据库迁移说明见 [手动记录和版本收藏测试报告](docs/MANUAL_RECORDS_TEST_REPORT.md)。

## VIP 复盘分享

登录后由管理员开通 VIP。结束对局并主动发布本人的复盘，打开记录编辑器或已收藏的本人版本中的「对外分享」，生成 / 复制只读链接。普通房主不自动拥有生成资格；首版只支持作者分享自己的已发布帖子。

访客持链接可匿名查看本局身份、结果和最新主动发布内容，不建立玩家身份。保存或提交私人草稿不会改变公开内容。复盘撤回、VIP 到期 / 取消、账号禁用会暂停链接；恢复后未撤销的链接可恢复。主动撤销后旧链接不会恢复；重新生成立即使旧地址失效。首页「我的分享」独立管理本人链接，即使取消收藏、撤回复盘或删除活动房间，仍能撤销；VIP 到期也保留撤销能力。

地址使用当前浏览器访问的域名。在同一 Wi-Fi 下分享给手机，请从 `http://电脑局域网IP:3000` 生成链接；`localhost` 链接只能访问各自的本机。Render试用站可生成公网地址，但分享及正文也依赖临时数据库，尚未做公网完整分享验收。剪贴板不可用时页面提供可长按复制的地址。验证证据见 [复盘分享测试报告](docs/SHARING_TEST_REPORT.md)和 [Render试用记录](docs/RENDER_TRIAL.md)。

### 基础故障定位与语音默认

夜间公共播报默认开启，复用管理者已有交互激活声音；手动关闭后本设备保留选择。闭眼间隔只播“请闭眼”。已发布记录弹窗支持正文与评论整体滚动。服务器提供脱敏错误编号、读取健康检查及后台故障/恢复日志，完整范围和未完成告警/保留配置见[排查说明](docs/SERVER_DIAGNOSTICS.md)。最新改动未部署，真实iPhone声音仍需单独验收。

暂停时在“管理→未来投票设置”调整后续投票秒数/票型公开程度；确认页显示已保存旧值到新值，未变项标注“不变”，返回可继续编辑。读取失败需重试，其他管理者更新后需重新确认；当前已进入的投票设置和计时不变。完整边界见[差异对照](docs/WEREWOLF_RULES_SPEC.md#future-vote-diff-2026-10-19)，本地实现、未部署。

当前管理者可在“管理→查看管理记录”或“记录→查看管理记录”查看暂停/恢复、临时房主授权、未来投票设置及房主警徽接管的操作者、时间和前后变化，支持刷新/更早分页。仅公开变更，撤权后不可读；详细边界见[规则](docs/WEREWOLF_RULES_SPEC.md#management-history-2026-10-17)。本地接入，未部署。

自动对局白天可点“我的身份与技能”查看本人身份和实际技能余量；默认收起，关闭、切后台或进入新阶段后需重新点开。不会显示历史验人结果，测试操作演员切换也仍只看本人。完整条件见[规则](docs/WEREWOLF_RULES_SPEC.md#day-self-2026-10-17)。本地接入，未部署。

赛后复盘及自动对局收藏只返回最终有效事实，不再附带完整运行过程；已有收藏继续可读，原件、名称和日期保留。个人笔记、已发布版本及官方纠错历史不变；完整边界见[规则](docs/WEREWOLF_RULES_SPEC.md#final-replay-2026-10-17)。本地接入，未部署。

房主在赛后记录页确认提交“修正官方记录”后，官方帖子、有效分享页及分享收藏自动显示最新官方事实和修订历史。个人推理仍须主动发布；原始发布事实可展开查看，VIP个人版本不被覆盖。页面沿用30秒可见重读及回前台刷新，完整边界见[规则](docs/WEREWOLF_RULES_SPEC.md#official-sync-2026-10-18)。本地接入，未部署。

房主赛后可在“官方修订与发布”点击“仅自己收藏”，自动保存当前草稿，免费加入首页“我的收藏”；“未发布 · 仅本人可见”入口只允许本人按需查看。不会发布、分享或开放评论；首次主动发布后同一收藏转为发布版本。切后台关闭私密内容，详细边界见[规则](docs/WEREWOLF_RULES_SPEC.md#private-official-favorite-2026-10-18)。未部署。

首页“我的记录”现在位于收藏之前：点击“添加 / 编辑记录”→选择已有可写对局，即可进入原编辑页；已有记录也可点“编辑记录”。“我的笔记”和“保存笔记”在编辑页前方。房主或有效VIP开始对局后可使用，归档写权限不扩展。“我的收藏”默认只显示最近3条，筛选收起，可点“查看全部收藏”展开。完整[展示规则](docs/WEREWOLF_RULES_SPEC.md#record-entry-compact-favorites-2026-10-18)。
