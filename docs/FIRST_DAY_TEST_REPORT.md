# 第一天与测试自动跟随验收 — 2026-10-10

## 已实现

- 测试房间默认自动跟随当前行动身份：首夜指定狼人确认者、女巫、预言家、猎人；白天报名、发言、投票、死亡技能和警徽操作玩家。可关闭后手动选择。仅可控制模拟玩家与房主本人。
- 第一天包含警长报名、发言与退水、投票和 PK；首夜死讯；统一死亡技能询问、猎人线下目标录入、连锁死亡、遗言和警徽处理；顺序或自由发言；放逐与 PK。
- 按用户确认，先竞选警长，再公布首夜死讯并立即判胜。死讯公布前所有玩家仍可参与竞选。胜负确定立即结束；12 人板白痴被放逐翻牌并死亡。
- 警上吞毒不公开、不返还毒药、不能指刀。PK 发言期间按用户确认限制自爆，正式投票期间所有狼人禁止自爆。投票全弃分别处理为警徽流失或无人出局。
- 公共与私人状态分离，服务端校验操作者、当前阶段和回合。投票中不公开他人票型。第一天状态、截止时间及已提交操作持久化。
- 白天界面沿用浅色圆角风格，阶段信息、12 个座位和主要操作集中在手机屏幕内。

## 当前本地服务

localhost:3000 已启用测试玩家并更新，健康检查通过。更新前已备份数据库；既有 2129、4921 房间保留首夜完成状态，无重新发牌。进入原房间后，房主点击「开始第一天」即可继续。

电脑访问 `http://localhost:3000`。手机与电脑连接同一局域网，访问 `http://电脑局域网IP:3000`，电脑需保持服务运行；不同设备拥有独立身份，同一浏览器标签共享身份。房主新建并入座后可「补满测试玩家」，准备、发牌、开始首夜；自动跟随默认开启。
