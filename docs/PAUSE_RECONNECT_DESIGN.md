# 暂停、临时房主与重连（2026-10-10）

依据 V1 第七节和后续手机交互覆盖。继续开发授权沿用用户直接执行要求，保持现有工作区和已有对局。

暂停 / 恢复状态独立保存在服务器。原房主和获授权的存活临时房主二次确认后可暂停，冻结有效阶段截止时间、技能、票型、测试推进和阶段切换；恢复二次确认后全员等待 5 秒，再从原阶段、原剩余时间继续。暂停不重置身份、药剂、提交或 turnId。暂停没有次数或时长限制，服务重启后保持。

原房主可以授予 / 收回一个存活参赛玩家的临时公开管理权限，原房主死亡后仍可管理。临时权限不能访问他人身份或夜间技能，也不能转授。玩家死亡后临时权限自动撤销。公开流程与秘密技能仍由不同服务器权限检查负责。

连接按服务器验证过的成员和全部订阅连接统计。最后一个连接断开才算离线，另一标签或同账号另一个客户端在线时不算离线。登录轮换凭据后仍依据相同成员恢复。断线记录持久化，服务器重启时清除旧的在线标记。

普通断线不暂停。夜间有效神职尚未提交操作、发生本阶段断线或仍离线时，在阶段截止处补足实际丢失的操作时间，最多 15 秒；尚未重连补最多 15 秒。每名玩家每局一次，不能在已切换阶段补交；狼人和闭眼间隔不延长。已提交技能、死亡 / 技能耗尽角色不额外申请宽限。公开只显示统一的连接异常提示，不显示座位、角色或宽限使用者；所有成员断线都使用同一提示，避免仅秘密角色断线产生特有播报。

暂停期间可批量调整未来投票的默认时长和票型公开程度，二次确认保存；当前阶段 / 当前截止时间不变化，进入后续投票设置时使用新默认。不开放身份、核心规则或手动切回自动设置。

手机操作区保留紧凑控制入口；暂停 / 恢复准备时全员看到同一遮罩和剩余时间。私人操作在暂停、断线及页面后台时隐藏。管理和配置使用独立弹层，不扩大正常游戏主操作区。
