# 公共语音播报验证（2026-10-10）

## 实现范围

自动对局中，房主或有效临时房主可从「管理 → 开启公共播报」开启本设备中文语音。主屏没有增加按钮或高度；管理弹窗可在小屏内滚动。纯手动模式不运行自动播报。

覆盖当前公开流程：夜晚睁闭眼、狼人最后30秒提醒、警长报名 / 退水 / 发言、手机和线下举手投票、有效票结果、警长结果、已公布死讯、统一死亡技能询问、公开发动后的线下目标录入、遗言、警徽移交、白天发言、暂停 / 恢复 / 统一重连提示及胜负。死亡神职保留相同夜间提示。公共语音不包含秘密身份、刀口、药剂、查验、吞毒或尚未公开的技能状态。

`packages/domain/voice.ts` 只读取公开 RoomSnapshot 的白名单字段。`publicDeathSkills` 只根据已经结束的公开技能询问及后续公开阶段生成结果，避免猎人在两次轮询之间开枪时被误播为“未发动技能”。终局优先，不补播过期询问。

服务器维护单房间单标签租约、有效会话权限和持久化派发键。租约15秒，浏览器每2秒轮询；单请求最多5秒，独立250毫秒检查租约失效。新登录撤销旧会话时租约同步删除。普通参赛者不能开启播报；同身份两个标签也不能同时持有租约。公开投影没有增加秘密读取或技能代操作权限。

切阶段取消旧音频；同阶段报名 / 投票更新不会丢弃合法提示。隐藏页面、断线、失去管理权限、退出房间或切换纯手动时停止并释放。刷新需重新开启，已派发历史提示不补播，可手动重播当前提示。播放失败不修改规则、时限或胜负。

## 验证方式与边界

服务端测试使用独立 SQLite 数据库、模拟时钟及真实本地 HTTP / Socket。浏览器测试使用 Chrome、独立 cookie 上下文和真实服务，运行在3100端口及内存数据库，不操作开发房间。

语音 E2E **仅替换设备 SpeechSynthesis 边界**，收集页面实际提交的文本、启动 / 完成 / 错误回调及取消次数。它验证客户端与服务端完整链路，不验证真实声音、音色、音量、Safari 用户手势限制或锁屏行为。实际可听 Chrome 音频、真实 iPhone、多部实体手机均未测试。

手机主屏在320×568、390×844、430×932的桌面 Chrome 模拟视口下验证无纵向溢出。管理弹窗允许滚动；这不代表真实 Safari 工具栏、键盘和安全区已经验收。

## 审查与修复

独立只读审查发现的问题均补了失败复现和修复验证：

1. 两次轮询之间猎人完成开枪后误报未发动：改为公开完成结果，服务端测试确认不会误播。
2. 租约过期响应可能在下一次检查前播放：接收时先校验租约，增加请求超时及独立失效检查。
3. 同阶段报名更新增加 revision，合法提示被丢弃：有效性同时核对阶段 scope，保留同阶段提示。
4. 开启期间切阶段取消启动音频，导致新响应未初始化租约：移除音频序号门槛，保留请求代次及权限守卫。
5. 设备 speak 同步抛错后 busy 残留，不能再次开启：先设置 busy，启动音频后检查请求代次；同页面恢复设备后可重试。

公共文本派发成功不等于设备实际播放成功。浏览器不返回可靠音频完成凭证，重播只针对当前公开阶段；不会重新执行技能或还原旧阶段。
