# 假面舞会：现行确认规则与实现索引

日期：2026-11-01（America/Los_Angeles）。来源：[Issue #14](https://github.com/yup005/note_wolf/issues/14) 的最终49A；Owner 在本线程批准设计并回复「去实现」。以下保留稳定 MASQ ID，确认规则与测试/部署状态分开记录；MASQ-041 是已作废的历史决定。

## 固定配置与边界

官方 `masquerade-12`：3 普通狼人、1 假面、4 平民、预言家/女巫/白痴/舞者各1。新增 `dancer`、`mask` 与 `masquerade` ruleset；同阵容副本可独立保存，官方不可覆盖。新角色混搭仍阻止开局；不新增9人模板、机械复制或跨板判胜审计。旧板、旧归档和现有全局规则版本保持兼容。

## 人数兼容性审查（PEOPLE-009 / Issue #17）

- 官方及已验证可玩范围均为12人：`minPlayers=12`、`maxPlayers=12`；本板最低12人，6–11不支持，13–16变体待独立角色/技能/判胜验证与授权，17及以上不支持。全局6–16是产品边界，不使任一板自动支持全部人数；全局旧1–256配置实现的迁移属于Issue #17，本批不扩展到其他板。
- 必需角色：3普狼、假面、4民、预言家/女巫/白痴/舞者各1。首版不允许增删核心角色或改变共享狼组数量；非同阵容副本可保存但不能自动/手动开局，不静默走其他ruleset。
- 开局普通狼有刀，假面首夜无技能且不入刀队；零普狼初始配置不合法。合法对局三普狼全部死亡的下一夜假面才继承，超时空刀。真实狼完全出局即好人胜，夜终同时屠边狼优先。
- 夜初至少三人未入池才能形成新舞池，整局资格耗尽提示不能舞；假面两份技能目标分别耗尽时验证跳过，其他技能可继续，不随机制造违规。共享60秒和夜初候选快照不因预计死亡变动。
- 跨人数自动验证含6/7/8、min-1=11、min=max=12、max+1=13、16/17，以及缺核心/零普狼配置；合法12人覆盖跨夜耗尽、日间判胜、首夜终局模拟、自动/手动、复盘/重启/同房新局。真实设备另验。13–16保持未批准，不宣称Ready。

## 已确认裁决

- **MASQ-001（1A） 假面查验与戴面具**：从**第二夜**起，假面每夜可以先查验 **1 名玩家当夜是否进入舞池**，再给 **1 名玩家**戴面具；查验对象和戴面具对象可以不同。假面行动及超时按 MASQ-020（25B）随机补齐未完成技能；查验/戴面具历史分别按 MASQ-009、014、017、018 保存，自动操作仅从合法未使用候选中选，不能自动造成违规点杀。

- **MASQ-002（2A） 面具目标范围**：可选择**任意存活玩家（按字面包含假面本人）**，不要求其已入池；若目标当晚**未进入舞池**，该次面具不产生舞池阵营翻转效果。真实身份、预言家查验与屠边身份始终不变。若 Owner 后续另定禁止自戴，需显式收窄本条。

- **MASQ-003（3A） 舞者同晚死亡**：舞者当夜已经选定三人，即使舞者自己也被普通狼刀杀死，**已选三人的共舞仍正常结算**。仅因本夜死亡不撤销已成立技能。

- **MASQ-004（4A） 夜间同批死亡**：共舞成员即使同时遭狼刀/毒杀，**仍按入夜已锁定的三名舞池成员计算**，不先从舞池剔除；之后聚合所有实际死因，最终死亡名单去重，统一判胜。

- **MASQ-005（5A） 不足三人**：尚未入池且仍存活的合法目标不足 **3 人**时，**本夜不发动共舞**，不可挑选少于3人凑数。舞者本人界面允许显示「今晚不能舞」（MASQ-011），不能向其他玩家泄露名单；不足3人时不随机凑出非法三人。

- **MASQ-006（6A） 自爆限制**：**假面不能自爆**；普通狼人保留标准合法自爆能力。不能使用通用狼人自爆入口绕过角色限制。

- **MASQ-007（7A） 第二夜及之后的固定顺序**：**舞者 → 假面 → 普通狼人（或合法继承刀权者）→ 预言家 → 女巫**。先记录舞池，再由假面查验及戴面具，再刀人，再查验真实阵营，最后女巫；**首夜已确认狼人→女巫→预言家（MASQ-023，28B）；舞者60秒（MASQ-033）、假面查验+戴面具共用60秒（MASQ-034）、普通狼/继承刀人180秒（MASQ-035），预言家30秒、女巫首夜60秒/以后30秒沿用当前项目已确认通用时限**。已确认顺序优先于外部资料的不同排序。

- **MASQ-008（8A） 公告限制**：**天亮默认仅公布正式死亡信息，不自动公布舞池三人名单**，不公开戴面具对象或假面查验结果。具法定私密权限的参与者可查本人操作记录，赛后复盘沿用现有权限与发布流程。

- **MASQ-009 假面重复查验点杀本人**：假面在同一局中**不得重复查验曾经查验过的人**（不是仅限制连续两夜）。如果假面在后续任意一夜实际提交了对已查验目标的重复查验，**假面本人被点杀**。记录整局查验过的目标，跨夜、断线与重启持久保留，重新开局时重置。查验记录与戴面具记录分开，不能把仅戴过面具的目标当成已查验。

- **MASQ-010 舞者重复共舞点杀本人（Owner 最新明确选择 B）**：每名玩家整局最多有效入池一次。舞者在后续夜晚**确认提交**的三人名单中，或**截止超时时仍保留的未确认选人草稿中**，只要包含至少一名曾经有效入池的玩家（MASQ-026，30B），**舞者本人被点杀，整次共舞取消**：本夜不形成有效舞池、不进行阵营少数方击杀，也不产生本次共舞带来的免狼刀保护。不可将被重复选择的玩家直接点杀。点杀在紧接着的白天天亮死亡公告中公布。整局有效入池历史与违规事件跨夜、断线和重启持久保留，重开新局重置；一次合法请求的网络重试不能当作第二次选人。**已由 MASQ-012（17A）明确：无效名单所有玩家不新增入池次数。**

- **MASQ-011 无舞池提示**：如根据 MASQ-005，本夜剩余存活且尚未入池的合法玩家不足3名，无法正常组成舞池，系统**可以明确提示舞者本人「今晚不能舞」**并跳过正常共舞选择；不能强行选择少于3人或把没有舞池视为舞者点杀。此提示属于舞者本人的私密操作状态；公开界面不公布入池历史或候选名单。

- **MASQ-012（17A）违规舞池不消耗资格**：舞者确认名单中含整局已有效入池过的玩家，舞者本人点杀、**整次共舞取消**；当晚这份无效名单中的所有玩家（包括原本未入池的玩家）**均不新增入池次数**。旧有合法入池记录不撤销。无舞池少于3人时按 MASQ-011 直接提示跳过，不强行凑人数。

- **MASQ-013（18B）假面违规查验中断剩余技能**：假面重复查验此前任何一夜已查过的玩家，触发假面本人点杀；**本夜随后戴面具技能立即取消，不能继续给人戴面具**。已完成的此前夜晚有效操作/历史不回滚。要求在服务器端拒绝违规者继续提交面具行动，不得仅隐藏前端。

- **MASQ-014（19B）每人整局最多被假面戴一次面具**：假面不能在本局第二次把面具给同一名玩家，**无论两次相隔多少夜**；查验历史和戴面具历史分别记录，限制彼此独立。**重复戴面具点杀假面本人（MASQ-017，22A）**；给未入池玩家戴面具同样消耗其整局一次的名额（MASQ-018，23A）。

- **MASQ-015（20A）点杀夜间统一结算**：舞者/假面违规点杀与本夜正常狼刀、女巫、共舞产生的死亡**同一批夜间统一结算、聚合去重、之后判胜**；点杀者本夜视为出局，但**紧接着的第二天白天才公布死亡**，夜间公共界面不提前透露。多种死因并存不能重复出局，必须保留可信事件来源。这一批死亡导致终局时按 MASQ-030 **天亮先公布死亡名单，再公布胜负**。

- **MASQ-016（21A）假面继承刀权**：**三名普通狼人全部出局后，存活假面从下一夜开始独立拥有狼刀**；可以自刀、可以空刀，且**保留自己的查验舞池和戴面具技能**（只要未违规死亡、技能仍有合法目标）。有普通狼人存活时假面不参与其共享投刀，也不看狼队成员名单或投票。继承后的同一夜按已确认顺序：舞者 → 假面查验/戴面具 → 假面继承狼刀阶段 → 预言家 → 女巫。若普通狼人当夜出局，**当夜既有狼刀不被追溯替换**；下一夜起才改为假面单刀。假面存活本身仍属于存活狼人阵营，不因三普狼全灭就提前判好人获胜。

- **MASQ-017（22A）重复戴面具点杀**：假面整局每名目标只能戴一次面具。无论相隔几夜，只要**正式提交对曾经戴过面具目标的再次戴面具**，**假面本人被点杀**；本次重复面具不作为新的有效面具。按 MASQ-015 夜终合并死亡、次日白天公告；不得因普通网络重试或界面重绘误判第二次主动施放。

- **MASQ-018（23A）未入池仍消耗面具名额**：假面第一次有效给某存活玩家戴面具，即使该玩家当晚没有入池、面具当夜对阵营计算无影响，**仍消耗本局对该玩家唯一一次戴面具资格**，不能在后续夜再给同一人面具。已有效选择应持久保存到整局历史。

- **MASQ-019（24A）舞者超时随机补满3人**：有至少3名存活且**整局此前没有有效入池**的合法目标时，舞者若未在截止前确认完整3人，服务器在已选择且可保留的合法目标基础上，**随机补齐至三名互不重复的合法玩家**，成立本夜舞池并正常结算。自动补选不得选已经入池的玩家以故意触发点杀；若截止时仍保留包含已入池者的违规草稿，改按 MASQ-026 点杀并取消共舞，**不运行自动补选**；截止时无重复草稿时才按 MASQ-019 自动补齐。若合法候选总数不足3，严格使用 MASQ-005/011：提示「今晚不能舞」、不随机凑人、不点杀。

- **MASQ-020（25B）假面未操作/超时随机代操作**：第二夜起假面本人未在相关阶段完成的查验、戴面具行动，截止时由服务器为**未完成的行动随机挑选合法目标并执行**；已经有效确认的行动不改动。若重复查验/重复戴面具触发点杀，则按相应规则立即停止后续假面技能，不替违规玩家补做新面具。随机选人必须排除本局查验过/戴过面具的目标，保证系统不会制造违规点杀。合法随机目标耗尽按 MASQ-025 自动跳过并私下通知本人；不得强行随机非法旧目标或擅自点杀。

- **MASQ-021（26A）免毒依旧耗药**：女巫给舞者或假面下毒，目标因其角色免毒而不被毒死，但女巫**毒药照常消耗一次**。同夜不得再使用解药（既有通用约束），记录毒药消耗和免疫原因，不在公共夜间信息提前暴露身份。

- **MASQ-022（27A）解药仅救狼刀**：女巫解药只能抵消有效狼刀死亡，**无法救由舞池少数方产生的死亡或违规点杀**。狼刀与共舞伤害同夜命中同一人时，即使成功救掉狼刀，也不能抵消共舞死亡；同批死亡结算去重后再判胜。

- **MASQ-023（28B）首夜固定顺序**：**首夜普通狼人 → 女巫 → 预言家**，舞者和假面首夜**不执行技能**。与第二夜起已确认的 **舞者 → 假面 → 狼人/继承刀权者 → 预言家 → 女巫** 是刻意不同的本板专属顺序，不能默认复用标准12人或狼女孩夜间流程；舞者/假面/继承刀具体时限已由 MASQ-033/034/035 定案；闭眼后5秒阶段间隔沿用通用 N-001。

- **MASQ-024（追加 Owner 反馈）随机动作私密告知实际目标**：舞者被系统随机补人后，必须仅向**舞者本人**显示**最终参与共舞的全部3名玩家/座位**（包括原已有效选择者），而不是只告诉「系统已代选」；假面查验和戴面具因超时被系统随机执行后，必须仅向**假面本人**显示各自**最终实际操作目标**及适用的查验结果（是否入池）。行动是本人确认还是系统补选须可被本人区分并在断线重连后重新读到已锁定的结果。不可向其他玩家、普通房主、公共播报、白天通告或公共 Socket 泄露。对于需要确认查验结果后再戴面具的具体提示时点应与阶段时序一致，不能提前透露尚未执行的动作。

- **MASQ-025（29A）假面无合法目标**：本次查验/戴面具若已没有任何合法随机目标，**自动跳过该项技能并私下明确提示假面本人**，不暂停对局、不随机已用过的目标、不因系统无目标点杀。仅该项技能跳过；如另一个技能还有合法目标则按原流程继续。

- **MASQ-026（30B）舞者未确认重复草稿超时也点杀**：舞者手动选人草稿中含**此前有效入池过的玩家**，即使尚未按下「确认」，**若直到本阶段截止时该重复草稿仍存在，亦算违规**，舞者本人被点杀、**整次共舞取消**，本次草稿中的所有人不新增入池次数、不产生共舞少数方死亡/舞池狼刀保护。**不能**在超时时自动丢弃重复草稿并随机补人救场；仅无重复违规的未完成草稿适用 MASQ-019（24A）随机补齐。若在截止前已清除/修改重复草稿且没有正式确认违规，则按最终合法草稿处理；保存草稿和超时触发事件须幂等。

- **MASQ-027（31A）假面被点杀后取消继承狼刀**：若假面在自己查验或戴面具阶段违规点杀，即使此前已取得独立继承刀权，**本夜后续假面刀人阶段不再实际执行刀人**。后续假面技能/刀口授权由服务端立即阻止。**“点杀当夜末统一加入死亡、次日公布”并不意味着违规后还可继续发动后续技能**（与 MASQ-015 不冲突）。公开夜间阶段仍保留防泄密的统一外观/播报。

- **MASQ-028（32A）免刀目标的原始刀口可见可救**：舞池免狼刀保护已经生效时，如狼人选中的刀口落在受保护玩家身上，女巫在有查看刀口资格时仍**看到原始刀口**；若解药尚在、目标符合通用救药限制，**可选择使用解药且解药照常消耗**。舞池免刀本身不被撤销，不应将守卫的「同守同救奶穿」套用于本板舞池免刀；其他非狼刀死亡（舞池少数方/毒/点杀）仍不能靠解药抵消。未用解药的后续夜间才享有看刀口的通用限制继续适用。

- **MASQ-029（33A + Owner 补充）舞者可自行入池、三人全免狼刀**：舞者可以把自己选为三名共舞玩家之一。只要本夜舞池**合法、有效成立，且名单包含舞者本人**，当夜这三人（含舞者本人）**全部免疫普通狼人刀和假面继承后的狼刀**；不能只保护舞者，也不能只保护另外两人。此保护**不免共舞少数阵营死亡，也不普遍免女巫毒**（舞者本人另有角色免毒）。舞者**不在**舞池时，不因其职业让另外三人免狼刀；舞者同晚遭刀死而合法池仍结算按 MASQ-003。若重复选择触发无效池/点杀则**没有**这次舞池保护（MASQ-010/026）。

- **MASQ-030（34A）夜终判胜、公告顺序**：夜间统一结算后若已满足胜利条件，立即进入终局公告（MASQ-043 最新覆盖），**不再启动警长竞选**。公告仍先公布本夜死亡座位（不公开死因），再公布获胜阵营与游戏结束；其他板子原 R-005 特例不受改写。

- **MASQ-031（35A）双方同夜同时满足胜利条件，狼人优先**：先在夜终聚合所有死亡（含点杀、狼刀、共舞、毒药），再按本板显式**屠边判胜**：仅一方满足则该方胜；若**狼人胜条件（全神或全民出局）与好人胜条件（全部真狼人含假面出局）在同一夜同时满足**，**狼人胜**。面具只影响舞池计数、绝不改变真实阵营或终局计算；三普通狼全死、假面仍存活不算好人胜。白天判胜/其他板子不被这一条覆盖。

- **MASQ-032（36A）白痴沿用标准12人**：本板白痴**仅白天被放逐时翻牌，翻牌后正常死亡**，计为神职出局；不继承14人「白痴双边」或机械白痴翻牌加刀等特殊规则。其他被刀/毒/舞池等方式死亡不触发额外翻牌特权。按本板真实四神口径计算是否屠神。

- **MASQ-033（37A）舞者选择时限60秒**：第二夜起舞者的行动窗口为**60秒**（服务端单一截止时间）。提前有效确认三人可结束该行动；截止时合法名单不足3人则按 MASQ-019（24A）随机从合法目标补满，且私下向舞者展示**最终完整三人名单**。如截止时仍保留已入池玩家的重复草稿，按 MASQ-026（30B）**点杀舞者、取消本次共舞**，不得自动改成合法名单。不足三名合法存活候选时按 MASQ-005/011 提示「今晚不能舞」。网络延迟/断线不能重置服务端倒计时。

- **MASQ-034（38B）假面查验+戴面具共用60秒**：第二夜起，假面**查验舞池与戴面具两步骤合计只有60秒**，从假面角色阶段开始到同一服务端绝对截止时间，**不**是两段各30/60秒，也不能因提前确认查验而重新获得60秒。先执行查验再执行戴面具；角色提前合法完成两步骤可提前结束，未完成的技能在截止时先采用**该技能服务端最后保存且仍合法的草稿目标**；没有合法草稿才按 MASQ-020 从**各自整局合法目标池**随机补做（若无合法对象则 MASQ-025 跳过并私下告知），遵照 MASQ-040（44A）。出现重复查验/重复戴面具而点杀本人，立即禁用后续动作、继承狼刀（MASQ-013/027）。

- **MASQ-035（39A）假面继承刀权180秒**：三普狼全部出局后的**下一夜**，假面的单独刀人阶段设**180秒**上限，沿用狼队刀人时长；可以在截止前确认自己刀人目标或空刀。该刀人阶段与先前假面查验/戴面具的60秒窗口**彼此独立**，位于假面技能阶段之后；如果此前在假面阶段违规点杀，则此处只运行对外无泄密的虚拟狼人阶段，不允许实际操作。普通狼人存活时普通狼队仍按既有180秒投票/确认规则执行。

- **MASQ-036（40A）死亡隐私**：公共公告仅公布死亡座位，不公布狼刀、毒药、点杀、共舞死因，不公布舞池或假面行动。终局时按 MASQ-030/043 直接公布死亡座位→获胜阵营/游戏结束；不举行警长竞选。内部授权赛后复盘保留死因。

- **MASQ-037（41A）本夜初始存活快照决定目标候选**：当夜所有技能（舞者选人、假面查验/面具、普通狼/假面继承狼刀、预言家查验、女巫救毒）目标资格统一以**本夜开始时已存活玩家的快照**为基础，并结合该技能的**整局次数/舞池历史/自身限制等独立规则**过滤。即使目标本夜被另一技能预计杀死/违规点杀，其他角色**不应从目标列表或私密界面提前获知**，仍可以选该夜初始活着的目标，夜末统一结算。**这仅定义目标资格，不授权被点杀或已失去技能权的施法者继续行动**：MASQ-013/027 违规后立即禁用该施法者剩余技能。上一夜已确认死亡者不在快照中，不能被选择。

- **MASQ-038（42A）假面查验结束立即显示结果**：假面**确认查验目标并锁定结果后，立即只向本人显示该玩家当晚是否入池**，然后允许在**同一60秒窗口剩余时间内**选择戴面具目标。查验结果只体现舞池事实，不泄漏真实阵营/他人身份；面具目标可不同于查验目标。若查验动作拖到60秒截止仍未最终确认，系统**优先执行合法已保存草稿，没有才随机代查**，在截止时**立即锁定并私下显示实际查验目标及结果**，同时按 MASQ-040 优先使用合法已保存面具草稿、没有才按 MASQ-020 随机补戴（或 MASQ-025 自动跳过），**不得再给额外的手动戴面具时间**。在这种“到截止才代查”情形，提示应展示最终自动查验和自动戴面具结果，而不是承诺玩家能在截止后作出新的手动选择。本人授权查看/断线恢复须读取同一已持久化结果，不能重抽、不能向公共语音或他人泄露；**持续查看权限截至本夜结束（MASQ-039），不延长60秒行动窗口、不开放白天历史查询**。

- **MASQ-039（43B）假面自动结果可查看至本夜结束**：假面本人经合法授权可以在**本夜剩余期间的私密页面**查看其已锁定的查验目标、是否入池结果、戴面具目标，以及哪些是系统超时代操作；包括60秒截止后已执行的自动动作。**不延长原本共用的60秒行动窗口，不允许截止后再次选择**。断线重连时在**同一夜内**可以恢复读取同一结果，不重新随机/重做技能；本夜结束后撤销此夜行动结果的实时私密访问，白天不能借此回看历史验人或面具动作。其他玩家、普通房主/管理员和公共语音不可获知。已确认的角色本人身份/剩余技能白天展示沿用通用规则。

- **MASQ-040（44A）超时优先采用最后保存的合法草稿**：假面查验、戴面具**共用60秒**。某一步到绝对截止时若尚未按最终确认，但服务端已有该步骤**最后保存且仍合法的目标草稿**，则**用该目标作为该步最终执行对象**，而不是再随机。只有该步骤未留下合法已保存目标时，才随机选择整局未使用的合法目标；若池已耗尽则按 MASQ-025 自动跳过、提示本人。完整执行仍按「先查验（立刻私密返回入池结果）→ 后戴面具」时序，即使两步在截止事务中连续锁定也不能额外给手动时间。若某一步明确提交了违规重复目标并已触发点杀，MASQ-009/017/027 优先，禁止用合法随机或旧草稿洗掉违规记录。**最终49A（MASQ-044）已确认：未确认的非法重复草稿保留到截止，直接点杀假面，不准重新随机消除违规；截止前删除/修改掉违规草稿则不点杀。**

- **MASQ-041（45B，已作废，仅保留历史）**：此前决定首夜已终局仍举行警长竞选。**Owner 最新 MASQ-043 明确推翻此决定，禁止实现旧45B。** 任何夜晚只要已完成夜间统一结算且满足胜利条件，立即进入终局公告，不举行警长竞选。

- **MASQ-042（46A）假面继承狼刀超时视为空刀**：三普狼全灭后下一夜，假面在独立180秒继承刀阶段**没有最终确认有效刀人目标或明确空刀**，截止时**自动空刀**，不随机刀杀任何人。若已确认刀口则锁定该目标；已确认空刀则保持空刀。因违规点杀而失去刀权时，不执行实际刀人，且公开阶段仍维持虚拟播报隐私。该继承刀规则与假面查验/戴面具未操作时随机代选（MASQ-020/040）**不同**，不可共用随机逻辑。

- **MASQ-043（现行终局）**：覆盖 MASQ-041。任何夜夜末统一结算已经判胜，跳过警长竞选与尚未开始的普通白天流程，先公布死亡座位（不公开死因），再宣布胜利阵营/游戏结束。非终局首日仍竞选，不按人数推断胜负。

- **MASQ-044（最终49A）**：假面未确认的重复查验或重复面具草稿保留至共用60秒服务端截止，同样点杀本人。优先级为已确认违规→截止非法重复草稿→合法已保存草稿→无草稿随机合法未用目标/无候选跳过。截止前清除或改为合法草稿且从未确认违规则不点杀；版本号与事务锁定最终快照。处罚后停止剩余技能和继承刀，合法已完成查验保留审计，夜末死亡去重，重试不重复处罚。结果仅本人本夜实时可查。
