# 规则与界面调整验证 — 2026-10-10

本次调整按用户最新指示覆盖 V1 的相应默认行为，其余规则沿用既有验收基线。

## 实现

- 女巫确认救人、用毒或不用药后，正式与测试房间均立即进入 5 秒闭眼间隔。重复相同请求不再次用药、不重置间隔；换选项、过期阶段仍拒绝。未确认或死亡角色保留操作上限。
- 首夜女巫最多 60 秒；从第二夜起，女巫、预言家、猎人统一最多 30 秒。死亡神职的虚拟窗口时长相同。
- 女巫中刀显示“解药不可自救”，禁用救人，服务端拒绝自救；未用过药不等于可在当夜自救。
- 女巫用药、预言家查验、猎人技能状态在操作区高亮。女巫本夜收据可在闭眼间隔及之后本人重新查看；他人不收到该收据。切后台、断开连接、手动隐藏会遮罩结果。
- 狼刀、优先指刀、救人、毒药、预言家查验、猎人开枪目标必须存活。死亡座位禁选，伪造请求由服务端拒绝。尚未公开的当夜死者不提前改为公开死亡。
- 首次警上自爆后延续已报名、已退水和 PK 候选人状态；次日直接进入退水 / 自爆，再投票，不重新报名、不继续发言。已公开死亡的候选人排除，只有一人立即当选；新夜死讯公布前仍可参选。
- 原警上报名者退出后仍不能参与首轮警长投票；PK 台外存活玩家可投。延期 PK 候选人自爆后只剩一人时，另一人当选；第二次普通中断永久失徽。
- 房主选择“手机操作”或“自由发言”，替换原界面“顺序发言”名称。手机操作保留警左 / 警右、单死死左 / 死右和明确起点；自由发言由房主结束整段。旧 ordered 请求兼容映射为 phone。
- 投票设置提供独立“开始手机投票”和“线下举手”按钮。手机投票计时并由每人提交；线下举手无录票倒计时，由房主直接录入候选人总票数、确认公布结果。未录按 0 票，支持警长 1.5 票，服务端校验总人数、重复候选人、死亡目标、不可能的半票数和房主权限。汇总录票不伪造个人票型。
- 结束页面用大字高亮“好人获胜”或“狼人获胜”，明确所有狼人出局或屠边原因。白天移除常亮开关，必要阶段仍显示倒计时；夜间保留常亮开关。
