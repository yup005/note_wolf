# 准备与发牌：本轮交付与验证

日期：2026-10-09（America/Los_Angeles）。产品：笔记狼人杀。

验收基线：详细需求 V1；范围按用户批准的准备与发牌设计。本轮不代表完整自动法官或完整 V1 已通过。

## 实现内容

- 发牌方式与游戏模式独立设置，四种组合均支持准备与身份锁定。
- 房主必须占座，12 座齐全、12 人准备后才能开始发牌。
- 发牌前本人可改选空位或取消入座；事务防止同座冲突，每人最多一座。发牌后锁定座位和设置。
- 改配置清除全员准备；改座位清除本人准备。准备请求绑定设置版本，拒绝迟到的旧配置确认。
- 线上服务器随机发牌，数量固定为 4 狼、4 民、四神各 1；每人查看并确认自己的身份。重复发牌或开局不重新分配。
- 实体牌由本人秘密录入；收齐后校验数量，不匹配时全员看到统一检查文案，没有错误玩家或角色差额。开局前本人可修正，开局后锁定。
- 私人接口只通过已鉴权会话定位本人。房主管理权不扩张读取权限；他人查询参数、代提交字段和陌生会话被拒绝。
- 公共 HTTP / session / Socket.IO 投影不含 role、roles、identities 或设备凭证。私人响应禁缓存，身份不存 localStorage。
- 手机主要操作位于座位列表前，紧凑房间号与板子，深灰主按钮、16px 输入、44px 触控；身份默认遮罩，页面隐藏、断线和阶段变化后收起。

## 本机与手机访问

本机服务已在当前 checkout 重启，运行 `npm run dev`，监听 `0.0.0.0:3000`。电脑打开 http://localhost:3000 。本轮读取到的局域网 IP 是 `10.9.50.182`，同一局域网手机可尝试 http://10.9.50.182:3000 。地址随网络变化，用 `ipconfig getifaddr en0` 重新查询。

启动前保存 SQLite 备份 `.data/lobby.before-preparation-20261009.db`。测试服务用 3100 / 内存数据库；未把测试房间写入开发数据库。localhost 冒烟只建立匿名设备会话，没有创建演示房间。

同浏览器标签共用身份。请用不同手机或独立浏览器配置模拟不同玩家。普通 HTTP 局域网下复制和其他安全上下文 API 可能受限，可手动复制房间号。
