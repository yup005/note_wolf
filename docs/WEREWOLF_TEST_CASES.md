## 管理员测试权限验收（2026-10-11，BETA-004，本地实现；执行结果见验证报告）

- 开启测试的允许环境中，游客或普通账号即使是房主，也不显示测试入口；直接请求补模拟玩家、模拟身份/技能、代操作及阶段推进入口均拒绝，HTTP/Socket状态不改变。
- 管理员只在本人主持的独立模拟房可使用原工具；仅本人一个真人成员时可转换，之后其他真人包括旁观者不能加入、恢复列表或订阅。模拟角色列表不含本人，本人走原私人身份接口；真实玩家不能成为模拟接口的读取或代操作对象。
- 管理员注销、会话失效或接管后，旧 HTTP 秘密／命令请求拒绝，旧 Socket 断开；新管理员会话保留原房间与身份。
- 旧版本遗留真人成员的测试房，模拟接口、自动准备／确认及阶段推进均拒绝；设置／发牌失败回滚，真人成员不能继续 HTTP／Socket 旁观，原数据保留。
- 生产默认继续关闭测试；2026-10-11后续确认允许Render试用站例外，仅管理员的独立模拟测试房。验证普通账号/游客、真实玩家房、非隔离房及其他生产环境均不可用；限定服务需同时有测试开关、`render-trial`范围和正确平台服务标记；仅一个开关、错误服务／范围均关闭。本地实现，当前线上仍关闭；源码与执行证据见 [当前验证](TEST_REPORT.md)和 `tests/admin-test-rooms.test.ts` / `tests/e2e/admin-test-rooms.spec.ts`。
