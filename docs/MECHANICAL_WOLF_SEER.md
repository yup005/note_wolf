# 机械狼通灵师板子 — 需求讨论稿

> Updated: 2026-10-10
> Status: **部分已确认 / 其他待讨论**。供产品讨论与 Codex 阅读；**不授权自动实现未决规则**。
> 规则基准：京城大师赛机械狼通灵师；明确的线下约定优先于网络通用版本。

## 已确认

1. 基础预设为 **12 人机械狼通灵师**（并非人数上限，现已允许增加人数与角色）：通灵师 ×1、女巫 ×1、猎人 ×1、守卫 ×1、平民 ×4、普通狼人 ×3、机械狼 ×1。
2. **从第一夜起，每晚机械狼固定在女巫行动结束后行动**，不因学习到的身份而移动夜间位置。设计目的：避免顺序变化泄露场外信息。机械狼未学习、已学习或技能耗尽时都保留这一固定阶段；具体法官提示待定。
3. 机械狼可以第一夜不学习，推迟到第二夜、第三夜或更晚夜晚再选择；一次成功学习后不得重选。
4. **拟态查验**：机械狼尚未学习时，通灵师查验结果明确显示 **「机械狼」**；成功学习后，查验显示学习目标的身份，而非「机械狼」。
5. 学习状态和原始身份分开：原始机械狼身份不变，另记录学习目标、学习夜晚和学习所得身份。不能将查验身份误当真实阵营。

6. 机械狼只能选择**其他存活玩家**作为学习对象，不能学习自己或已出局玩家。

7. **学习通灵师**：从成功学习后的下一夜开始，每夜可以查验一名仍存活的其他玩家，获得其具体身份；不能查验自己或出局玩家，可以重复查验同一人。对机械狼的查验按其当时的拟态状态显示（未学习为「机械狼」，已学习为其所学身份）。真正通灵师与机械狼的查验行动、结果、记录必须相互隔离，不向对方泄露；机械狼阵营不变。

8. **学习女巫**：仅获得一瓶毒药，不获得解药；从成功学习后的下一夜起可使用；全局仅一次，可选择暂不使用并保留；毒药不受普通守卫守护保护；若真正女巫与机械狼同时毒杀同一玩家，仅记一次死亡，但分别保留两个毒杀来源记录。

9. **学习猎人**：获得猎人开枪技能，学习成功当夜立即生效。机械狼因狼人刀杀或白天投票放逐出局时可以开枪；因真正女巫或机械狼的毒药毒杀时不可开枪。开枪最多带走一名仍存活玩家，也可选择不开枪。真正猎人是否已死亡，不影响机械狼已复制的开枪能力。

10. **学习守卫（已确认部分）**：从学习后的下一夜起可每夜使用守护技能，**不限整局使用次数**；机械守卫具有**「弹毒」**效果：若任意来源的**女巫类型毒药**（包括真女巫与机械狼复制的女巫毒药，未来也适用于其他能够释放同类型毒药的角色）毒杀机械狼当夜守护的目标，该目标不因这瓶毒死亡，毒药反弹至**实际施毒者**，使施毒者死亡。**允许守护自己，但不能连续两晚守护同一玩家（包括自己）**（与普通守卫一致）；**机械狼守卫与真守卫守护同一目标时，不互相抵消；若该目标仅受到普通狼人刀杀，则仍存活。** **多种施毒者同时毒同一被守护目标，各自毒药分别反弹，实际施毒者分别死亡（1A）**；即使实际施毒者还受到狼刀攻击，仍分别保留来源、只计一次死亡（3A）；施毒者受到普通守卫保护也不能阻挡反弹毒（4A）。**机械守卫自守并自毒时，毒反弹至自己，仍然死亡（2A）**。其他复杂连锁仍待确认。

11. **学习普通狼人（已确认部分）**：学习后获得**整局一次**的额外破盾刀，而非每晚额外一刀；可保存到后续任选的机械狼夜行动阶段使用，使用后永久消耗。该刀能突破守卫类保护，需与普通狼刀分别记录。**启用前提已确认**：必须等所有普通狼人出局、机械狼继承普通狼刀之后，额外破盾刀才可使用；即使已学狼，只要普通狼人仍存活就不可使用。**同夜双刀已确认**：继承普通狼刀后，可在同一夜的狼人阶段以普通狼刀攻击一名玩家，并在女巫之后的机械狼阶段使用一次性额外破盾刀攻击另一名玩家（例如普通刀 5 号、破盾刀 6 号），两刀均进入当夜结算。**同目标双刀已确认**：普通狼刀与一次性额外破盾刀允许指向同一名玩家；两刀分别记录，破盾刀可突破守护，死亡仅计一次。**破盾范围已确认**：额外破盾刀可以突破普通守卫的守护，**不能突破机械狼复制守卫技能产生的守护**；目标如果受到机械守卫保护，不能仅凭破盾刀判定死亡。与多种保护/其他伤害的组合仍待讨论。

12. **学习平民**：成功学习后不获得任何额外技能；通灵师查验机械狼显示「平民」；机械狼真实阵营始终为狼人；所有普通狼人出局后，机械狼仍可继承普通狼刀；学习平民后不能重新学习其他身份。

13. **狼人身份互认**：普通狼人不知道机械狼的玩家身份，机械狼也不知道普通狼人的玩家身份。双方不共同睁眼，普通狼人夜间集体行动与机械狼的固定独立行动阶段必须严格隔离，不向任一方透露另一方的身份。

14. **普通狼人可以刀杀机械狼**：机械狼不免疫普通狼人狼刀。若普通狼刀目标是机械狼，按照正常狼刀与当夜保护／救助效果结算；机械狼是否死亡取决于完整结算结果，不因同属狼人阵营而豁免。

## 狼刀继承、胜负与阶段（2026-10-10 本批确认）

- **狼刀继承以入夜时为准**：若该晚已经没有任何普通狼人能够在普通狼人夜睁眼带刀（例如最后普通狼人白天自爆或放逐），机械狼**当晚**就在狼人行动阶段继承狼刀；如果普通狼人入夜时仍可带刀、只是当夜稍后死亡，不在当晚中途转移狼刀，下晚再判定。
- 机械狼不论学习了何种身份（包括未学习、平民及其他技能），在上述条件满足时均继承普通狼刀；**可以自刀、可以空刀，但不能自爆**。
- 采用**屠边**规则；机械狼仍算狼人，好人获胜需要消灭全部狼人。机械狼通常可被毒杀，若存在有效保护（例如复制守卫后当夜合法自守）则依保护与毒药反弹规则结算。
- **胜利判定先于猎人／机械猎人开枪**：若一次已确认的死亡立即达成终局，直接结束游戏，不再触发猎人或机械猎人开枪。例如最后一神猎人死亡即狼胜、不得开枪；最后一狼机械猎人被放逐即好人胜、不得开枪。若尚未结束且死亡原因符合开枪条件，才可开枪，开枪后再次判断胜负。
- **继承狼刀和复制技能允许同夜兼用**。狼刀在**狼人夜**执行（普通狼人阶段先），复制技能在固定的**女巫之后的机械狼夜**执行；即使机械狼狼夜自刀，也先记录行动、在机械狼阶段允许提交合法技能，再统一按攻击／保护／毒药等交互结算，不在提交刀时立即更改存活状态。
- 已学习普通狼人的一次性额外破盾刀仍受先前确认的继承前提；其与普通刀可同夜且可同目标，破普通守卫、不破机械守卫。

## 夜间结算补充（2026-10-10 确认）

- **机械狼继承狼刀后自刀 + 当夜合法的机械守卫自守**：狼刀被守护阻挡，机械狼存活（不连续自守等已确认限制仍有效）。
- **机械狼自刀 + 真女巫解药**：解药可以救机械狼，按有效救助处理。
- **机械守卫保护的目标同时被刀且被女巫类型毒药命中**：普通狼刀被挡、毒药弹向实际施毒者，施毒者死亡；被守护目标不因这两次攻击死亡。其他独立伤害仍须分别结算。
- **机械狼学习女巫后允许自毒**：可将自己选择为毒药目标，照常纳入夜间毒药结算；若与弹毒等效果冲突，依各有效效果裁定，不能擅自假设自毒必死。
- **同夜双方终局优先级**：夜间所有已提交的合法攻击、守护、治疗、毒药及反弹等先统一结算，再判胜负。如果最终同时满足「全部狼人死亡」与「所有神职死亡」或「所有平民死亡」，**狼人获胜**。不得因夜间发现最后一狼死亡就提前终止尚未结算的同夜行动。
- **日间有序事件**：放逐等死亡事件生效后立即判胜负；一旦终局，不再触发后续猎人／机械猎人开枪。未终局且符合条件时才触发开枪，并在开枪死亡后再次判胜负。

## 学习时机与夜间信息（2026-10-10 本批确认）

- 学习当夜**拟态立即生效**；查验显示当前已学习身份。
- 学习目标当夜最终死亡，仍然视为成功学习（前提是学习选择时目标属于合法的存活对象）。
- 机械狼在学习当夜死亡，学习结果仍记录于官方事件／复盘，但不由此继续获得行动机会。
- 复制守卫后可以选择**空守**；复制通灵师后可以选择**空验**，不得强制目标。
- 女巫只看到**普通狼人行动阶段**的狼刀目标（包括机械狼继承狼刀后在该阶段提交的普通刀）。机械狼行动阶段使用的**一次性额外破盾刀完全不向女巫暴露**，不显示刀口或提示额外目标。
- **同目标双刀 + 女巫解药（最新纠正，以此为准）**：普通狼刀与额外破盾刀同夜指向 5 号，女巫只看到普通狼刀 5 号并对 5 号使用解药，**5 号死亡**。解药仅救下普通狼刀，额外破盾刀仍生效；破盾刀对女巫隐藏，双刀分开记录、死亡只计一次。此前一度写为「5 号存活」系用户口误，已撤回。若破盾刀单独命中一个未被女巫看到的目标，能否被以其他方式使用的解药救助，仍待讨论。

## 夜间顺序、行动入口和超时（2026-10-10 已确认）

- **夜间固定流程**：机械狼开刀状态确认（只在需要时单独唤醒）→ 守卫 → 普通狼人行动阶段 → 女巫 → 机械狼学习／复制技能阶段 → 通灵师 → 猎人状态确认。机械狼固定的学习／技能阶段永远在女巫之后，不能随复制身份移动。
- **机械狼刀权确认早于守卫**：每夜按入夜时普通狼人是否还具备行动刀权来确认机械狼是否继承狼刀；此处是刀权确认，并非提前执行机械狼复制技能。机械狼继承狼刀后，具体出刀仍按照已经确认的狼人刀阶段办理，且先于女巫与机械狼学习／技能阶段。
- **第一夜特例**：第一夜机械狼确定没有刀权，**无需守卫之前额外睁眼**，只在女巫后睁眼一次进行学习或空过；之后若进入无普通狼人能够出刀的夜晚，才出现前置刀权确认环节。若既有刀权又有复制技能，保持两段行动且不得混成一段。
- **女巫**：第一夜**不能自救**；同一夜**不能同时使用解药与毒药**。
- **通灵师**：可以连续多夜查验同一玩家，也可选择空验；夜间独立行动在机械狼之后。
- **猎人**：保留夜间独立状态确认阶段。
- **超时默认**：机械狼学习超时→空过（不消耗学习机会）；机械狼复制技能超时→不使用；继承的狼刀超时→空刀；通灵师查验超时→空验。无需为这些超时默认暂停等待法官。
- **实际狼刀提交阶段已确认**：机械狼继承狼刀后，在**普通狼人行动阶段**提交普通狼刀目标，而非在守卫前的刀权确认阶段提交；前置确认仅检查刀权。额外破盾刀与复制技能仍在女巫之后的机械狼阶段提交。普通狼人和机械狼互不认识，不共享私密刀口信息。
- **各夜顺序相同的原则**：以上为统一的阶段次序，但第一夜省略不可能有刀权的机械狼前置睁眼，避免多余操作。需将「前置刀权确认」与「实际普通狼人阶段如何让机械狼提交继承狼刀」的用户界面设计成不泄露信息的流程，Codex 不得改变已经确认的技能结算顺序。

## 玩家反馈与法官操作（2026-10-10 本批确认）

- **学习反馈**：机械狼学习成功后，立即仅向机械狼本人私下展示所学身份；不对普通狼人或其他玩家公开。
- **固定阶段**：机械狼学习完成、已耗尽一次性技能或已学习平民时，仍保留女巫后的机械狼阶段，避免行动阶段变化形成场外信息。
- **破盾刀余量**：机械狼复制普通狼人时，本人的私密界面显示额外破盾刀剩余次数（1 或 0），并按继承刀权前提禁用未解锁的出刀操作。
- **查验确认**：通灵师看到查验结果后，需要主动点击确认才结束阶段；机械狼复制通灵师产生的查验结果也应采用同样的私密确认交互（后半条属于一致性 UI 建议）。
- **提交后不可由法官在夜间结算前修改机械狼行动**：本轮明确选择「不可以」。不可将法官的查看权限等同于更改权限；若要支持事故纠错，应另行讨论授权流程和审计规则，而非默认允许编辑。
- 不向其他玩家暴露机械狼的学习身份、复制技能及隐藏破盾刀。

## 玩家操作和信息隔离补充（2026-10-10 确认）

- **学习目标必须可选且存活**：已出局玩家在学习选择界面不可选，不能先选死亡玩家再报「学习失败」；仍遵守不能学习自己。服务端也必须校验，不因绕过前端校验而提交非法目标。
- **断线和重连**：沿用现有跨板子的通用断线／恢复／限时处理规则；不为机械狼另设断线即空过等特殊规则。以项目当前已确认的通用规则和代码为准，Codex 需查阅相应需求与测试。
- **操作提交不可撤销**：机械狼学习、复制技能和刀人等行为一旦正式提交，玩家不可撤回或更改。此前禁止法官修改机械狼已提交行动的限制不变。
- **学习平民彩蛋**：机械狼成功学习平民后，可以在仅机械狼本人可见的私密反馈中显示「你就是个**普通村民**!」，其中「普通村民」以红色强调（产品表达为红色文字；实际 UI 必须保证可读性）。这只是文案彩蛋，真实身份和阵营仍为机械狼／狼人，不改变技能或胜利判定。文案是否每夜重复显示尚未决定，默认不扩展为新的提示规则。
- **继承狼刀后的身份隔离**：机械狼在普通狼人阶段获得单独的刀人界面，**不显示其他普通狼人身份信息**。已公开自爆的普通狼人属于例外：其已公开的自爆身份可以被机械狼知道，但不得据此推断或额外显示尚未公开的狼人身份、历史私密行动。
- **学习反馈内容**：前一轮已确认学习成功立即展示所得身份；本轮未额外修改该决定。

## 多人数配置、装甲狼规则版本和跨角色复制（2026-10-10 新决策）

- **可配置人数与角色**：12 人仅是默认预设，支持 13、15 人及进一步扩展，按角色配置与人数匹配验证，不得将 `12` 写死在逻辑中。
- **配置包含装甲狼**，即自动采用「机械装甲」规则版本，详见 [MECHANICAL_ARMOR.md](MECHANICAL_ARMOR.md)；无装甲狼时维持本文件的机械狼通灵师规则。**两套规则互斥，不能同时套用弹毒/破盾刀与机械装甲专属无敌盾/双刀叠加规则。**
- 机械装甲规则中**没有额外破盾刀，也没有弹毒**；机械守卫的保护是无敌盾。普通刀与额外一刀同目标可破**普通盾**，但不可破机械守卫的无敌盾。
- 装甲狼在机械狼之后行动；只有普通狼人和机械狼都死亡，装甲狼才能带刀。
- 机械狼学习装甲狼获得双刀狼能力；装甲狼学习已拟态的机械狼时，**连同复制到的技能一起获得**；若机械狼尚未学习成功，则装甲狼获得双刀狼能力。
- **13 人混子**：无特殊主动技能，个人胜负跟随榜样所属阵营；混子被刀死时，屠民判定允许在剩 1 名普通平民时成立。机械狼学习混子无额外技能。
- **15 人扩展示例**：默认基础配置上 +1 平民、+1 普通狼人、+1 白痴。机械狼学习白痴后，如果作为最后一狼出局，**可以额外入夜刀一次**（是此前“胜利判定先于机械猎人开枪”规则的明确新例外，终局必须暂缓至该特殊阶段结算；具体流程待讨论）。
- **先前的纠正规则仍有效**：在无装甲狼规则版本中，普通狼刀和额外破盾刀同目标、女巫救该目标，目标**死亡**（解药不抵挡额外破盾刀）。
- 机械装甲、混子、白痴等新增规则**已进入联合开发需求范围**，但特殊交互仍有未决项，在确认前不得让 Codex 擅自补全。

## 可扩展产品架构（2026-10-10 确认）

- **固定板子模板必须保留**：支持选择预设人数、角色、规则版本，一键创建；同时支持用户自由增加人数、角色及角色数量，不把 12 人作为硬性限制。
- **统一的可复用技能复制机制**：角色真实身份、技能实例、复制来源、剩余次数、复制时间及生效状态分别存储；装甲狼学习已拟态机械狼时创建独立完整次数的技能副本，学习时冻结，源角色后来改变不影响副本。不能针对每一对角色组合硬编码特殊分支。
- **以角色列表切换规则**：含装甲狼即切换机械装甲规则（其一刀额外一次、无敌盾挡全部狼刀及毒药、无独立破盾刀、无弹毒等），不含则采用此前机械狼通灵师规则。
- **统一可扩展胜利结算**：屠神、屠民、全狼死亡、混子榜样归属及「混子被刀后留一民」、机械白痴作为最后一狼触发的额外夜间行动、同步死亡的优先级等由单独的规则层计算，必须按当前板子规则评估，不允许直接用固定人数/固定狼种做判断。
- **新增确认**：机械装甲的额外刀整局一次；装甲狼复制已拟态机械狼获得独立完整技能次数、复制时冻结；混子第一夜选择榜样；机械白痴最后一狼触发的额外夜晚，其他仍存活角色仍正常行动。详见 [机械装甲规则](MECHANICAL_ARMOR.md)。

## 拟议的数据／交互要求（待确认后细化）

## 待核实，禁止自行假设

- 已确认实际普通狼人阶段提交继承狼刀；仍需确认前置刀权确认在实际玩家端如何提示、是否睁眼，以及不泄露场外的 UX。
- 学习当夜拟态立即生效、通灵师在机械狼后查验已确认；仍需编写同夜拟态查验的验收用例。

- 机械守卫的多重毒药／反弹链以及复杂多来源伤害叠加；额外破盾刀在复杂叠加保护下的结算，以及继承狼刀后的其他夜间交互。
- 夜间多来源致死/保护的精确结算；除本批确认的超时默认外，断线/重连的细节仍待确认。

- 固定阶段在机械狼已出局、技能耗尽或获得狼刀后的主持人 UI 细节；学习平民彩蛋是否在后续夜晚重复显示待 UX 定稿。
- 多阶段同步死亡的复杂边界仍需独立验收案例；上面已确认夜间狼人胜利优先。
