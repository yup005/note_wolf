# 机械狼通灵师板子 — 需求讨论稿

> Updated: 2026-10-10
> Status: **部分已确认 / 其他待讨论**。供产品讨论与 Codex 阅读；**不授权自动实现未决规则**。
> 规则基准：京城大师赛机械狼通灵师；明确的线下约定优先于网络通用版本。

## 已确认

1. 采用 **12 人机械狼通灵师** 板子：通灵师 ×1、女巫 ×1、猎人 ×1、守卫 ×1、平民 ×4、普通狼人 ×3、机械狼 ×1。
2. **第二夜起机械狼固定在女巫行动结束后行动**，不因学习到的身份而移动夜间位置。设计目的：避免顺序变化泄露场外信息。机械狼未学习、已学习或技能耗尽时都保留这一固定阶段；具体法官提示待定。
3. 机械狼可以第一夜不学习，推迟到第二夜、第三夜或更晚夜晚再选择；一次成功学习后不得重选。
4. **拟态查验**：机械狼尚未学习时，通灵师查验结果明确显示 **「机械狼」**；成功学习后，查验显示学习目标的身份，而非「机械狼」。
5. 学习状态和原始身份分开：原始机械狼身份不变，另记录学习目标、学习夜晚和学习所得身份。不能将查验身份误当真实阵营。

## 拟议的数据／交互要求（待确认后细化）

- 记录 originalRole、learnedRole（可空）、learningNight（可空）和技能可用时机，避免身份拟态与技能触发时机混淆。
- 固定机械狼阶段由法官工具呈现，但不得通过跳过阶段、阶段标题或异常耗时公开透露所学身份。具体夜间提示方案待讨论。

## 待核实，禁止自行假设

- 第一夜完整的行动顺序（特别是机械狼与通灵师的相对顺序）；第二夜起女巫之后机械狼与通灵师等角色之间的具体顺序。
- 学习当夜的拟态生效点，与通灵师同夜查验的先后关系。
- 学猎人后开枪何时生效、毒杀是否禁止开枪。
- 学女巫毒药、学守卫一次性守护及是否挡毒、学普通狼人双刀及穿盾、普通狼人全灭后继承狼刀的精确交互。
- 机械狼未学习时遇到被刀、被毒、出局等边界；夜间超时如何处理。
- 固定阶段在机械狼已出局、技能耗尽或获得狼刀后的主持人 UI 细节。
