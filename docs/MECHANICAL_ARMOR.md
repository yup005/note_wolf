# 机械装甲板子 — 未来需求草案

> 记录日期：2026-10-10
> 状态：部分确认，未纳入当前机械狼通灵师开发范围；不要自动实现未决项。
> 本文件描述独立板子，不能与 `MECHANICAL_WOLF_SEER.md` 的「机械狼通灵师」混为一谈。

## 确认的规则方向

1. **机械装甲板子没有破盾刀，也没有弹毒**。此处指这一板子的技能设计，不能据此删除另一板子已确认的专属机制。
2. **机械守卫的盾是无敌的**：在本板子内生效的保护不被破盾技能突破。保护能阻挡哪些未来特殊伤害、是否保护反弹/特殊标记等复杂情况需另外确认。由于本板子不设置弹毒，不能错误触发弹毒死亡。
3. **装甲狼在机械狼之后行动**。需要在完整夜间阶段表中确定其相对其他角色的具体次序（是否紧接机械狼）。
4. **装甲狼的狼刀继承条件**：普通狼人和机械狼都死亡以后，装甲狼才可以开始带刀。继承发生在哪一个夜晚应依入夜状态进一步确认，暂不直接套用旧板子推断。
5. **机械狼学习装甲狼 → 双刀狼**。双刀的次数、时机、是否同夜/同目标、是否有优先级等尚需明确，不推断具有破盾效果。
6. **装甲狼学习机械狼 → 拟态身份**；**例外：若机械狼尚未学习技能，则装甲狼学习机械狼得到双刀狼**。需要进一步确认：学习机械狼已经拟态的具体角色身份，还是继承其当前的技能与验人反馈；以及若机械狼后来学习或状态改变是否同步变化。尚未确认的内容不可由 Codex 自行决定。

## 待确认

- 「装甲狼」与「机械狼」是否都存在学习动作、学习时间点及合法学习对象规则。
- 12 人板子具体角色构成、好人神职与普通狼人数量、胜利条件是否沿用屠边。
- 装甲狼行动阶段的具体位置以及入夜刀权确认/继承安排。
- 无弹毒且无破盾刀的确切伤害结算优先级；无敌盾是否挡普通刀、毒、双刀、其他扩展技能，以及能否自守、连守。
- 双刀狼的使用次数、是否独立两刀、是否能刀同一玩家、是否与女巫救助交互。
- 装甲狼学机械狼拟态时，机械狼本身是否应被展示为所学身份、学习目标技能的继承链和冻结时点。
- 本板子所有技能私密性和交互 UI。

## 开发边界

仅记载未来需求，不实现。不将本板子「无破盾刀／无弹毒／无敌盾」规则覆盖到机械狼通灵师；也不要把旧板子的「破盾刀／弹毒」应用于机械装甲。
