# 首夜操作测试报告 — 2026-10-09

## 已实现

- 房内座位优先布局：首页按钮与紧凑房间号置顶；板子、房主设置、测试控制台可折叠。发牌后身份确认优先，开局后隐藏准备与已准备标签。
- 普通玩家入座后只准备一次。自动模式锁定身份后，房主点击「开始首夜」直接进入狼人阶段，无需再次确认手机就绪。身份确认和秘密技能仍由本人操作。默认尝试屏幕常亮，可关闭，不支持时如实显示。
- 服务端首夜顺序与截止时间：狼人最多 180 秒 → 闭眼 5 秒 → 女巫 60 秒 → 闭眼 5 秒 → 预言家 30 秒 → 闭眼 5 秒 → 猎人查看状态 30 秒。
- 狼队私人票型更新、反复改票、指定随机确认者、平票随机、无人投票空刀；确认者断线不重抽。确认者可提前结束狼人阶段。
- 女巫解药和毒药各一次、不可自救、同夜不可双药、未确认超时不消耗；预言家只得到好人或狼人且仅当前阶段可查看；猎人只显示技能可发动/不可发动，不能在夜间射杀。
- 所有人默认一致的「查看操作」遮罩；非行动角色读取统一等待状态；阶段、演员、断线、后台变化立即遮罩。当前阶段的本页未提交选择在隐藏后保留，整页刷新读取已提交状态。
- 阶段、截止时间、指定确认者、秘密命令与药剂持久化；重复进入首夜不重置，重复同一技能确认不重复消耗。普通房主只管理公开入夜流程，不能代操作真实玩家。
- 开发测试房间可切换模拟角色及显式推进测试阶段；不提供真实玩家代操作，生产环境不注册测试接口。

- 本轮按用户明确决定，将角色之间闭眼间隔从 10 秒缩短至 5 秒；后端模拟时钟验证三个间隔在截止前仍闭眼、截止时进入下一角色。狼人私有票型按刀口目标分组，确认者独立显示；未投票与空刀明确区分。小屏狼人阶段目标区采用四列三行，保留至少 44px 触控高度。

## 明确未验收与后续边界

后端计时边界使用模拟时钟；浏览器流程使用开发版推进阶段，未在真实设备连续等待完整首夜。模拟玩家不是独立设备联机证据。独立真实会话的权限测试是 HTTP 测试；实际 iPhone Safari、浏览器地址栏动态收缩、安全区及实际屏幕常亮尚未实机验收。
