# 开发环境测试玩家

用户批准添加测试玩家，并要求可操作所有角色。现有准备流程的有限扩展：仅显式启用 WOLF_TEST_PLAYERS=1 且非 production 时注册接口。

房主独自创建并入座后，可将房间标为测试房间、补满 11 个服务端模拟玩家。他们没有可用的设备凭证，仅用于测试 UI 与准备 / 发牌；不是独立客户端联机证据。仅支持线上发牌，自动准备与确认自身身份，房主本人仍手动准备。

测试控制台可切换 12 座：房主座位使用正常私人接口，模拟座位使用开发专属且房主鉴权的接口。可操作准备、查看身份、确认身份。不得借控制台读取新加入的真实玩家身份；正常房间不提供控制台，正式环境不注册任何测试接口。房间测试标签持久化并向全员展示。

首夜与第一天已接入。测试房间默认自动跟随：夜间切到指定狼人确认者、女巫、预言家或猎人；白天依次切到尚未报名或投票的玩家、当前发言者、死亡技能玩家与警长。展示该玩家的对应操作，关闭自动跟随后可手动选座。房主公开流程始终用房主自己的权限执行；其他真实玩家不可代操作。测试房间提供显式推进计时按钮；普通房间没有测试推进或他人角色控制。具体证据见 FIRST_DAY_TEST_REPORT.md。

2026-10-10 后续更新：第二夜及后续白天已连接至胜负结束，测试身份直接显示；最新范围及证据见 [完整对局测试报告](COMPLETE_GAME_TEST_REPORT.md)。本文保留阶段验收历史。
