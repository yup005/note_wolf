## 继承优先级（已确认，不要重复问产品负责人）

**机械装甲 = 机械狼通灵师已确认基础规则 + 装甲狼加入后的明确差异覆盖。** 机械装甲文件没有逐条重写的共同机制一律继承基础规则，不意味着待确认；若本规格较旧的「未决项」将可继承规则列为未决，以此段为准。装甲狼的学习可延后、成功一次后锁定、学习目标须为其他活人；与普通狼人互不认识、不能自爆；继承刀权后允许自刀/空刀；复制能力默认按对应技能在基础规则里的生效时点。守卫可自守、不可连守同一对象、可以空守，装甲版机械守卫保护效果替换为无敌盾而非弹毒。已明示装甲专属的双刀、刀权条件、装甲狼在机械狼之后的阶段优先于基础规则。仍未由基础规则推出的**新交互**才需要决策。额外刀须继承普通刀后解锁，整局一次，目标可同可不同，已在本次对话确认。详见 [机械装甲继承原则](MECHANICAL_ARMOR.md#规则继承原则2026-10-10-用户再次明确优先适用)。

## 0. 目标与硬约束

- **增量扩展**当前 mobile-first 线下狼人杀辅助 Web App，保持现有 12 人预女猎白的在线/实体发牌、自动/手动法官、房间/座位/重连、日志与复盘、权限和 VIP 功能不回归。
- 同时提供**不可修改的系统固定模板**与**可编辑、可保存的自定义板子**。修改系统模板只能复制/派生个人配置，不得覆盖内建模板。
- 玩家总数等于角色数量；不硬编码 12。普通狼与平民可多个；**特殊角色暂不重复**（如不能两女巫、两机械狼、两装甲狼）；**允许零普通狼人**。
- 角色与技能解耦；复制技能为独立实例，存储真实角色、拟态查验角色、所属阵营、复制源与快照、触发时刻、charges、availableNight、lastTarget、公开状态、相关行动与效果 provenance。**不得为每一对角色组合硬编码独立结算**。
- 根据**实际配置是否含装甲狼**选 ruleset：没有装甲狼→机械狼通灵师规则；有装甲狼→机械装甲规则。系统模板也是该规则的输入，不仅靠模板名字。
- 角色为“狼刀组”（wolfpack）取决于其**与普通狼人共同睁眼带刀的行为属性**，并非角色名称。普通狼人、与普通狼见面的黑狼王/白狼王属于该组；后两者特殊主动技能本期不实现，不能因此预设这些技能。
- 前端与服务端都验证每次操作和权限；所有私密身份、刀口、学习结果、查验等仅适当玩家可见，公共 UI、管理员/临时主持和广播语音不得泄露。继承刀权的机械狼不认识未公开的普通狼人，只能知道已公开自爆身份。
- 已提交的机械狼操作不可撤销，法官也不能在夜间结算前改写。断线重连使用已有通用规则，不单独另写错误逻辑。
- **冲突配置允许法官手动裁定**：清楚标记自动结算无法判定的项目，不得静默猜测或误宣布胜负；记录裁定来源和结果，同时遵守现有权限制约。
- 未确认细节进入 `## 7` 阻塞/决策清单；可先实现与其无关的基础模块，不得自创玩法。

## 2. Role / Ability / Copy Engine

### 2.1 机械狼基础
- 原身份始终机械狼；机械狼与普通狼人互不认识、不同步睁眼；不自爆；能被普通狼刀杀或毒杀。
- 学习只可选当前合法**其他存活玩家**；允许一直空过；**成功学习一次锁定**。学习当夜拟态身份立即改变，若学习目标或本人该夜最终死亡，合法学习结果仍记录。
- 通灵师验机械狼：未学习→“机械狼”；已学习→所学身份（具体角色）。行动和查验结果各自私密。
- 复制通灵师：下一夜起每晚验一个其他活人，可空验、重复验、私密确认结果。
- 复制女巫：下一夜起有**一瓶毒，无解药**，可保留或对自己下毒；不能同夜多次投毒。
- 复制猎人：学习当夜立即获得一次符合条件的开枪机会；狼刀死亡或白天放逐可开枪、毒死不可开枪；**先胜利判定再开枪**，终局已成立不得开枪。
- 复制守卫：下一夜起每晚可守/空守，可以自守，不可连续两夜同目标，次数不限。两重守护不抵消。
- 复制平民/混子：无额外主动技能；学平民私密彩蛋“你就是个「普通村民」！”中的“普通村民”红字。无论学什么阵营仍是狼人。
- 复制普通狼人（无装甲狼 ruleset）：普通狼刀继承后获得**整局一次额外破盾刀**，可在机械狼阶段使用；可同夜与普通刀出、可同目标、破普通守卫但**不破机械守卫**。额外刀不提供女巫可见的刀口。
- 机械狼继承狼刀后，可**自刀/空刀**；狼刀在普通狼人阶段提交，复制技能在女巫之后独立提交，二者同夜可兼用。

### 2.2 机械装甲规则
- 只要配置有装甲狼，**不再有独立破盾刀或机械守卫弹毒**。机械守卫改为挡**所有狼刀和毒药**的无敌盾。
- 普通狼刀 + 一次性额外普通刀同目标可突破**普通守卫**，不能突破无敌盾。装甲规则的双刀是叠刀效果，不是一个带 pierce flag 的破盾刀。
- 机械狼学装甲狼→整局一次额外刀的双刀狼；装甲狼学未拟态机械狼→双刀狼。
- 装甲狼学**已经拟态的机械狼**→复制其对应技能，**独立完整次数**、**学习时快照冻结**；源机械狼以后改变状态/学习，不改变装甲狼副本。复制技能生效时点继承对应基础技能；具体私密反馈呈现待实现。
- 装甲狼行动在机械狼之后；只有普通狼刀组**和机械狼均出局**才获得普通狼刀。零狼刀组时机械狼优先第一夜继承，装甲狼等待其出局。

### 2.3 复用性合同
- `role` 是真实身份；`visibleRole(viewer, timestamp)` 是依 ruleset/学习状态可查验或公开的身份；`abilityInstance` 是有来源、库存、可用时机和使用记录的行为权利；互不混淆。
- 复制链取**当时能力快照**，新实例有自己的 charges，不共享源角色消耗计数。结算事件可追踪 `casterId / targetId / abilityType / sourceRole / ruleset / night / reflectTarget / preventedBy`；同一玩家因多来源死亡只产生一次出局事件。
- 不得在玩家提交刀/毒时立即标记死亡；先收集当夜行动→统一结算攻击、保护、治疗、毒及反弹→胜负判定。

## 3. Night Orchestrator / Privacy

- 标准顺序：机械狼刀权状态（需要时的前置确认）→守卫→狼刀组普通狼人阶段→女巫→机械狼复制/学习阶段→装甲狼阶段（如有）→通灵师→猎人状态。
- **前置只确认刀权，不选目标**；实际继承刀在普通狼人阶段提交；即使继承狼刀也不向机械狼展示未公开的普通狼人信息。
- 标准含狼刀组的第一夜无需机械狼前置睁眼，机械狼只在女巫之后睁眼；**自定义零狼刀组第一夜是例外**，机械狼可有刀权。
- 机械狼学习成功或技能耗尽、学平民时都维持相同固定夜间阶段，避免阶段顺序/语音/时长形成场外信息。装甲狼相同泄密风险需审核。
- 超时：学习→空过；复制技能→不使用；继承刀→空刀；通灵师→空验。断线复用原系统；通灵师验人可重复/空验，显示结果需玩家确认。
- 女巫首夜**不可自救**，同夜不可使用两瓶药；女巫看到**普通狼人阶段刀口**，但不看到机械狼额外刀，普通刀/额外刀是独立伤害来源。女巫刀口可见范围还需对齐现有“解药已用后不再可见”规则。
- 公开阶段/旁观者/其他狼不能看到机械狼的拟态学习结果、隐藏攻击、复制技能状态。不能因为端上隐藏但服务端广播全量事件而泄密。

## 4. Resolution / Victory Engine

- 无装甲狼：机械守卫守护可挡普通狼刀并**反弹所有女巫类型毒药到实际施毒者**；多人毒同目标→各自反弹；反弹毒普通守卫挡不住；机械守卫自守自毒，反弹到本人仍死；独立记录不同伤害来源。
- 无装甲狼：普通刀与额外破盾刀同目标、女巫对普通刀口用解药→**目标仍死亡**（额外破盾刀仍生效）。独立破盾刀破普通盾，不破机械盾。
- 有装甲狼：无弹毒、无独立破盾刀；无敌盾挡全部狼刀/毒药；两把普通刀同目标破普通盾，不破无敌盾。
- 狼刀与守卫/解药共同作用，以及毒药、反弹、重叠保护，须按 ruleset 生成**每个伤害来源的独立结果**再去重死亡；不可一刀救人便把额外刀一并取消。
- 入夜刀权用**可共同睁眼带刀的活跃狼刀组**判定：有狼刀组成员能带刀→机械狼尚不继承；没有→机械狼当晚（包含零刀组的第一夜）继承；装甲狼在机械狼与狼刀组全部出局后才继承。
- 屠边：狼方屠实际存在的神职边或民边；全狼死亡正常好人胜。**同夜双方同时满足终局，狼方优先**；夜间先统一结算再判胜负；白天已确认死亡→判胜负→若未结束再判猎人/机械猎人开枪资格。
- 混子仅一个，第一夜选其他玩家为榜样，个人胜负跟随榜样**原阵营**，榜样死亡不重选，混子真实身份不变；其出局（刀/毒/放逐均算）后，“剩一普通平民即屠民”，以及仅混子为最后民职时也算狼方屠民成功。必须分开“阵营赢者”和“混子个人赢者”。
- 机械白痴：机械狼学习白痴只获**特殊额外一刀**而非其他技能；若作为最后一狼**于放逐环节翻牌出局**，不能直接宣告好人胜，进入**额外一夜**（其他存活角色正常行动）；额外刀可自刀、可被守卫或解药保护。额外夜后若未满足狼方胜利→好人胜，不继续正常回合。狼刀/毒杀死亡不触发。
- 翻牌公开表现和普通白痴完全一致，只公开“白痴”并走普通翻牌展示，不公开狼人/机械狼/特殊刀权或额外夜触发原因。白痴/机械白痴翻牌后失投票权，白天仍有插嘴权；每位每一发言回合独立累计最多 **15 秒**，插嘴时**暂停当前发言者**的时钟，不能扣除别人的发言时长；下一发言回合重置。即便未来出现多个白痴也各自单独累计。
- 胜负判定使用独立策略/可审计理由，不得通过硬编码“最后狼死直接结束”“平民数清零才屠民”处理所有板子。记录结算证据。

## 7. 未决项 / Codex 禁止擅自决定

1. 【已确认／待实现】统一 §3 已给出机械狼→装甲狼→通灵师→猎人顺序，继承刀仍在普通狼人阶段提交；夜间私密 UI 及固定阶段防场外细节需实现和验收。若新增不能由此推出的交互，另列决策。
2. 【已确认】额外刀整局一次，继承普通刀后解锁，同夜可与普通刀指向相同或不同目标；装甲复制技能生效时点继承对应基础技能。此前未决措辞被继承原则及本次对话确认替代。
3. 【已由规则继承解决】装甲狼与普通狼信息隔离、不可自爆、取得继承刀权后可自刀/空刀；不要再次视为阻塞。
4. 【部分已由规则继承解决】机械守卫可自守、不可连续两夜同目标；无敌盾挡全部狼刀/毒药且不弹毒。其他尚未定义的伤害类型仍须另行确认。
5. 混子的榜样是否可以选翻牌未死角色、对验人结果的影响、死亡时“民职”分类及个别无民胜利边界；机械狼学习混子的拟态验人显示。
6. 机械白痴额外夜触发时已有其他胜利条件如何优先，翻牌视为死者还是失权存活者、白天触发状态如何与额外夜衔接。
7. 是否允许配置没有任意狼人、没有民+神；不合理组合如何提示、人工裁定记录的具体交互。
8. 原文档里**“首夜女巫不能自救”**和旧基础板的**“任何夜晚不能自救”**规则冲突：先按各自已确认板子的规格保留差异，不得无意修改现有预女猎白。对新板第二夜起能否自救需确认。
9. 第一夜“无普通狼刀组”的动态阶段与“默认首夜不前置唤醒”要依实际配置判断，不能硬编码。
10. 自定义板子包含多个特殊机制时，除已确认「含装甲狼即机械装甲规则」外的优先级必须另确认。
