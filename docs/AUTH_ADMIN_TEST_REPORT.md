# 账号、后台与最新手机交互验证（2026-10-10）

## 本轮实现

- 用户名密码注册 / 登录 / 退出。用户昵称持久化；游客仍可参赛，登录后关联已验证的本设备房间与收藏。同账号跨客户端保持一个成员、一个座位，同房间身份冲突时事务拒绝关联并保留双方状态。
- 随机盐与 scrypt 密码派生；只保存会话摘要，登录 / 注册轮换 HttpOnly 凭据，旧会话失效。独立账号的收藏互相隔离，可刷新和重启恢复。
- 唯一超级管理员通过本地初始化创建。后台查看用户、禁用 / 恢复用户、公开房间状态及已结束对局；禁用账号注销全部会话。普通房主不能访问后台，管理员不能读取进行中的身份、技能秘密或代操作。超级管理员不能被禁用。
- 去掉查看 / 隐藏操作按钮；本人阶段自动显示技能，其他人的阶段显示公共等待。后台、断线、角色切换、过期请求不能重新显示旧秘密。测试版继续自动跟随角色。
- 女巫确认后提前结束；预言家先提交查验并看结果，再点结束操作；猎人直接看到技能状态并确认已查看后结束。未提交仍使用原最大时长，角色间闭眼 5 秒。重试不会重扣药剂或重复查验 / 查看。
- 创建前去掉固定板子卡；创建后由房主在板子与设置中查看 / 选择，当前只开放 12 人预女猎白。其他板子明确未开放。
- 线下举手可选只录总票数，或逐人选择几号投几号 / 弃票。后者提交完整有效选票后由服务器计票，警长放逐票算 1.5；未录、重复选民、非法目标、非房主提交均不接受。
- 赛后直接展开身份；同轮夜晚与白天合并，死亡补到对应夜晚操作后。只显示最终仍留警玩家，警长 PK 淘汰 / 退水玩家排除；零票候选人省略，个人弃票保留。

## 本地运行

已一致性备份 `.data/lobby.before-accounts-20261010.db`，更新后比较 6 个已有房间，成员数、座位、夜晚 / 白天状态均未变化。唯一管理员已创建，初始凭据位于 `.data/admin-credentials.txt`，权限 0600、Git 忽略。已用独立 HTTP 会话验证实际管理员登录、用户 / 房间后台与退出均返回 200；未替换用户浏览器的会话。

电脑：`http://localhost:3000`。同一 Wi-Fi 下手机：`http://10.0.0.91:3000`（电脑 IP 变化时需更新）。服务继续运行，刷新即可加载新版本。
