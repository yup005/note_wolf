# Public Display Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for native sequential execution. Owner explicitly authorized continuous autonomous design/plan/implementation on 2026-10-21; no staged approval pauses.

**Goal:** 提供不授玩家权限的公共大屏。
**Architecture:** 原房主可撤销链接、专用白名单投影、固定轮询、现有根恢复边界。
**Tech Stack:** 现有Node24/TypeScript/React/SQLite/Playwright，无新增依赖。
**Spec:** [设计](../specs/2026-10-21-display-design.md)。保持当前干净work托管工作区，阶段本地保存，完整批次检查后提交推送。

## Global Constraints

只公开正式已知信息；夜间无角色阶段/小计时；不创建会话/成员/presence，不续期；测试房禁止；保留原权限/gameId/限流/PWA，无部署或合并。

## Review Focus

- 夜间不同秘密及私密提交改变内部revision时，投影不变，固定轮询不透露事件频率（任务1）。
- 公告前夜间死亡、未结票、手动未提交死讯不提前显示（任务1）。
- 跨房/测试房/伪造Cookie与display令牌不能调用游戏写API（任务2）。
- 轮换/撤销与迟到GET交错，旧投影不能在新代际显示（任务3）。
- 显示设备读取不能续期房间或触发神职连接宽限；重开/清理/重启仍正确（任务2/4）。
