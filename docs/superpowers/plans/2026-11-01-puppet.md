# 唯邻是从·傀儡 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Track progress in work/puppet-progress.md.

**Goal:** Implement GitHub Issue #15 as an independent playable 12-player board.

**Architecture:** Preserve original roles and knowledge; store the secret first-night conversion separately in the internal engine. Use a dedicated night adapter and resolution strategy, extending existing authenticated stores and final replay.

**Tech Stack:** TypeScript, Zod, React, SQLite, Node 24, node:test, Playwright.

**Spec:** https://github.com/yup005/note_wolf/issues/15 (updated 2026-11-01T20:32:32Z). Owner explicitly requested direct implementation, asking only about unanswered requirements.

## Global Constraints
- Exactly 2 wolves, 1 black wolf, 5 villagers, seer/witch/guard/hunter one each. No extra puppet role card.
- Circular neighbors (1/12 adjacent); server tries a complete deal once, retries only when no wolf neighbor is a god, uses second deal unconditionally. Never expose discarded cards or attempt count.
- First night: guard → puppet selection (180 seconds) → wolves → witch → seer → hunter. Only original wolves act together; puppet never learns conversion or inherits knife.
- At least one valid ballot required for early confirmer action. Timeout chooses highest valid tally, tied leaders randomly, all legal neighbors only when no valid ballots. Persist a single immutable lock.
- Conversion immediately disables guard/protection and witch effects (consumption/history unchanged), inverts seer feedback after effective alignment (self-inspection allowed), blocks actual hunter shots but keeps night status “can shoot”.
- Converted player exits original god/civilian counts and wins with wolves. Night simultaneous end gives wolves priority. Black wolf uses existing policy.
- Ended replay shows original roles, conversion event/time, effective alignment and victory basis. Live public/private projections preserve secrecy. Preserve other boards.
- No merge/deployment. Publish only after required checks pass; retain existing upstream work.

## Review Focus
- Duplicate requests/restart around timeout must not rerandomize conversion.
- Live host/admin/self-role/voice/socket views must not expose hidden state.
- Initial wolves all dead: maintain public night schedule, grant nobody new knife rights.
- Manual recording, return to auto, rematch, archive and statistics must retain effective alignment.
- Self-inspection, guard history, witch receipt and death skill permission must agree with server outcomes.
