# 新手提示与手机候场实施计划

依据[设计](../specs/2026-11-01-help-mobile-design.md)，按Owner“继续”在现有work工作区顺序实现，完成后审查并按仓库流程提交推送。

1. 增加浏览器回归：教学提示关闭/回看/刷新、单人候场/开局阻断、狼人引导关闭/恢复及非狼人不可见。先运行确认缺失行为。
2. 教学入口修复内边距和手机布局，增加可容错的本设备显示偏好；保留现有弹窗隔离及焦点。
3. 候场导航分层，局数移入详情并解释，明确候场人数不要求满员；游戏导航允许换行。
4. 在现有私密狼人卡中添加按相认、普通票型、优先指刀区分的简短说明；可收起并恢复，小屏在面板内滚动。
5. 更新规则/决策/用例/需求索引/进度，执行npm test、typecheck、build及完整E2E，审查差异，提交推送及验证远程SHA。

审查重点：偏好存储失败不能破坏页面；引导不能提前泄露身份；收起不能改动狼队选择；正式对局仍按板子人数检查；局数及规则入口始终可找到。
