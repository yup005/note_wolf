# iPhone PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for native execution, or superpowers:subagent-driven-development if the owner chooses delegated execution. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供iPhone主屏幕安装、安全静态缓存、断网提示及先校权再显示的恢复流程，保护所有既有秘密与未发布内容。

**Architecture:** Vite生成固定公开资源清单和Worker；生产静态服务明确文件类型、缓存头和SPA边界。根级恢复协调层先隐藏/卸载业务子树，再取得当前会话或实际分享授权，以新代际挂载；更新使用浏览器原生等待，不强制接管旧窗口。

**Tech Stack:** Node.js 24+、TypeScript、Vite 7、React 19、Express 5、Cache Storage/Service Worker、现有sharp、node:test、Playwright。优先无新增依赖。

**Spec:** [已审阅设计](../specs/2026-10-20-pwa-design.md)。Owner在设计交付后回复“继续”（2026-10-20），确认设计及后台丢弃未保存编辑、关闭所有窗口后升级两项取舍。随后Owner再次“继续”，批准本会话顺序实施。当前按下方步骤记录执行，实际结果见[报告](../../TEST_REPORT.md)；真实设备及生产仍另验。

## Global Constraints

- HTTPS主屏幕安装，Manifest `id/start_url/scope` 均为 `/`，名称“笔记狼人杀”，`display: standalone`，主题/背景 `#f7f8fa`；提供192/512普通PNG、512 maskable及180 Apple touch图标，沿用现有品牌。
- 只缓存构建清单中的哈希JS/CSS、指定安装图标和纯静态 `offline.html`。Manifest与在线HTML no-store；API/账号/房间/头像/分享正文/Socket/动态语音/POST不入Worker缓存，无离线动作队列、离线玩法或Push。
- Worker仅生产、安全上下文且支持时注册；开发模式不注册，普通浏览器和注册失败不影响联网流程。恢复权限保护不依赖安装或Worker能力。
- 后台、pagehide、offline先同步隐藏业务DOM，再卸载；恢复只读请求6秒超时。会话/分享请求成功前不重新显示旧内容；visibility/pageshow/online事件合并，不把online当授权成功。
- 后台/断网后未保存编辑丢弃，不自动保存、发布或提交技能；已保存服务器草稿及既有非秘密幂等意图键保留。旧代际读取、动作或账号响应不能更新新子树。
- 不调用 `skipWaiting`、`clients.claim` 或自动刷新；提示“新版本已准备，请先保存笔记，关闭本站所有窗口后重新打开”。旧窗口仍在使用时不得删除旧构建缓存。
- 服务器gameId/turnId/版本、Cookie、匿名分享credentials omit、VIP/管理员/法官及参与者权限、生产限流均保留；无数据库迁移、部署或PR合并。
- 仅合成内存/临时库和隔离3100/3101端口，不读真实库。Chromium模拟不代表真实iPhone安装、后台快照、锁屏/弱网或声音验收。
- 沿用当前work分支与既有主代理顺序执行偏好，完整交付批次统一文档/提交/推送；中间本地保存不逐步推送，最终fetch并核对远端SHA。

## Review Focus

- 公开静态路径返回200但正文是SPA HTML、重定向或no-store：安装必须失败且不留下半套新缓存，原联网应用继续运行（任务2/3）。
- 两个旧窗口未关闭且服务器已提供新构建：旧懒加载仍可读、新Worker持续waiting，不能清旧缓存或刷新未保存编辑（任务6）。
- 登录/退出请求在隐藏后才完成并改变cookie：旧回调失效仍需触发重新校权，不将旧响应体当新会话（任务4/5）。
- hidden、pageshow、visible、online与6秒超时交错，旧session/分享响应迟到：同步隐藏、合并新请求、只接纳最新代际，不闪现旧秘密（任务4/5）。
- 缓存被浏览器部分驱逐或首次根本未缓存，且设备离线：允许静态断网页或平台网络错误，不展示旧App、伪造接口成功或扩大缓存范围（任务2/6）。

## 文件边界与共享接口

- `apps/web/pwaBuild.ts`：`pwaBuild():Plugin`供Vite使用；`buildPwaMetadata(assets:PwaAsset[],policyTemplate:string):PwaBuild`确定性计算资源摘要。`PwaAsset={url:string;mime:'javascript'|'css'|'png'|'html';sha256:string}`，`PwaBuild={version:string;cacheName:string;assets:PwaAsset[]}`；清单作为Worker常量内嵌，测试从产物读，不新增可返回动态资料的API。
- `apps/web/pwaWorker.ts`：`renderWorker(build:PwaBuild):string`输出独立经典Worker脚本，类型不污染网页DOM全局；策略模板文本参与构建摘要。`apps/web/pwaTypes.ts`保存上述类型，不import业务contracts。
- `apps/server/frontend.ts`：`mountProductionFrontend(web:express.Express,root:string):void`，准确静态服务及文档回退；现有main生产分支调用它。
- `apps/web/src/sessionTypes.ts`：`AccountSession={account:Account|null;rooms:LobbyView[]}`；从现有AccountDialog移出，原文件re-export保持已有调用兼容。`RecoveryPayload={kind:'lobby';session:AccountSession}|{kind:'share';token:string;post:SharedRecord}`。
- `apps/web/src/recoveryLoad.ts`：`readSharedRecord(path:string,authenticated:boolean,signal:AbortSignal):Promise<SharedRecord>`；`loadRecovery(pathname:string,signal:AbortSignal):Promise<RecoveryPayload>`，分享路径先校验token并使用真实分享接口，不先建游客会话。
- `apps/web/src/recovery.ts`：`RecoveryState={phase:'checking'|'hidden'|'offline'|'failed';epoch:number;message?:string}|{phase:'ready';epoch:number;payload:RecoveryPayload}`；`createRecovery(load:(signal:AbortSignal)=>Promise<RecoveryPayload>,conceal:()=>void):RecoveryController`。Controller提供稳定引用的 `getSnapshot():RecoveryState`、`subscribe(listener:()=>void):()=>void`、`hide(reason:'hidden'|'offline'):void`、`resume():Promise<void>`、`retry():Promise<void>`、`dispose():void`；resume合并本轮检查，retry显式另起代际，hide同步conceal并使在途读取失效。超时常量6000ms。
- `apps/web/src/SessionBoundary.tsx`：`SessionBoundary()`协调可见性/联网事件与根级业务挂载；`App({initialSession,onSessionChange}:{initialSession:AccountSession;onSessionChange:()=>void})`只负责大厅/房间，新的恢复epoch作为key。分享分支直接挂载 `SharedRecordPage({token,initialPost?})`。
- `apps/web/src/pwaClient.ts`：`registerPwa():Promise<()=>void>`注册并提供监听清理；`hasWaitingUpdate():boolean`与`subscribePwaUpdate(listener:()=>void):()=>void`只保存/订阅当前页面内的waiting布尔状态，避免引导组件尚未挂载时漏掉提示；`PwaStatus()`负责按需安装说明和waiting提示，不持有业务响应。`main.tsx`在现有root挂载SessionBoundary。
