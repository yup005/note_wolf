# 公共语音播报

目标：线下面杀由一台管理设备播报当前公开流程，手机操作维持一屏；语音不决定或延长规则计时。用户已授权直接推进开发，延续当前自动法官 / 纯手动和身份隔离设计。

方案：采用设备 Web Speech 中文合成，无外部服务。固定录音对动态座位组合不方便，云端合成增加账号服务和联网依赖，本轮不采用。实际 iPhone 的音色、锁屏与浏览器播放限制仍需真机验收。

服务器只用 RoomSnapshot 公共字段生成白名单文案；不用角色私密接口、原始事件、昵称、未公布死讯、刀口、查验、药剂、吞毒或猎人未公开状态。保留死亡神职虚拟阶段，死亡询问一律“X号玩家是否发动技能”。无技能发动离开统一询问后播报“未发动技能”；终局优先，不补播陈旧流程。

单房间短租约绑定有效设备会话和标签 UUID，房主或有效临时房主可开启，其他客户端返回拒绝；租约过期可接管，同账号登录撤销旧会话时同步移除租约。服务器持久化已派发提示键，刷新 / 重连不重复补读历史。派发不等于音频已播放；播放失败可手动重播当前公开阶段，绝不改变游戏结果。

管理弹窗放开启 / 关闭、重播和状态，导航不加长。React 上下文跨夜 / 昼保留同一播报器，结束播报胜方。暂停和恢复替换队列；设备断线、退后台、回首页、撤销管理或进入纯手动时取消队列并释放租约，回来需手动开启。每次只读当前状态，取消过期响应 / 阶段音频，不积压已过去的阶段。

覆盖睁闭眼、狼最后30秒提醒、警长报名 / 退水 / 发言、手机 / 举手投票及有效票结果、警长当选 / 警徽流失、公开死讯、统一技能询问、公开发动后的线下目标录入、遗言、警徽移交、白天发言与胜负。公共重连只用需求的统一文案，不说玩家和角色；该提示时机推断风险继续记录 S-01。

公开状态补充 skillResults：仅在统一死亡技能询问结束并进入下一公开阶段后，输出座位、公开是否发动及时间，不输出角色或秘密命令。两次轮询之间完成开枪时，也不能误判为未发动。服务端派发键负责去重，初次开启不追溯旧技能结果。

浏览器开启、关闭和隐藏使用代次守卫；阶段变化可取消旧音频，但合法新阶段响应仍须初始化租约。请求最多等待5秒；收到过期租约不播放。相同阶段的报名 / 投票更新不使有效提示失效。单设备租约15秒，常规轮询2秒，独立250毫秒检查失效。实际音频未验收前，自动测试只替换设备 SpeechSynthesis 边界。
