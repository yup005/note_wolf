# 笔记狼人杀：准备与发牌设计

状态：用户已确认设计（2026-10-09），实现计划待审阅。

## 基线与本轮范围

以 `docs/WEREWOLF_REQUIREMENTS_V1.md` 为需求基线，审计文件用于识别验收缺口。用户最新确认：房主必须占座参赛。保留笔记狼人杀名称、白色浅灰卡片和简洁中文文案。

本轮完成房间、准备、两种发牌、身份确认与锁定，以及服务端权限和联机测试。自动法官和记录器作为后续阶段，不把身份锁定后的等待界面称作已完成对局。

## 方案选择

推荐在现有 SQLite / HTTP / Socket.IO 工程中新增准备领域模块和独立秘密身份存储：沿用会话和房间实时投影，领域规则与 React 分离。另一方案是立即构建覆盖全部夜间和白天的通用事件引擎；涉及三个未决事件顺序，且超出本轮范围，暂不选用。

## 配置与状态

房主在大厅分别选择发牌方式（线上随机 / 实体牌录入）和游戏模式（自动法官 / 纯手动记录）。默认线上随机、自动法官。两维独立，四种组合都有准备和身份流程；界面说明对局模块仍待开放。

状态依次为 `lobby` → `identity_collection` → `started`：

1. 大厅：自行选座、确认准备、房主设置。
2. 房主点击开始发牌：要求 12 座齐全、房主已占座、12 人均已准备。事务锁定配置与座位。线上牌同时随机分配；实体牌进入私人录入。
3. 每人查看并确认自己的线上身份，或秘密提交实体身份。
4. 房主点击开始：线上要求 12 人身份已确认；实体要求 12 人已提交且数量与板子一致。服务器锁定身份，进入已开局等待后续模块状态，不运行夜间计时、不判胜。

本轮不提供强制跳过准备、不提供重新发牌、不提供发牌后返回大厅。设置更新清除全员准备；座位变更清除变更者准备。二者都只允许大厅阶段。相同设置或同座重复请求不清除准备、不递增状态。

## 误选座位修正

提议：大厅阶段玩家可直接改选空位，或点击取消入座；只能操作自己的座位。改选原座位幂等，占用目标返回冲突且保留原座位。SQLite 事务保证同座最多一人、每人最多一座。开始发牌后禁止换座、退座和代换座，避免已知身份重抽与绑定错位。

此限制为本次用户已批准设计；实现时同步更新旧 L-01 记录。

## 秘密身份与一致性

身份枚举与数量来自独立领域板子：4 狼、4 民、预言家 / 女巫 / 猎人 / 白痴各 1。服务器用加密随机数洗牌并在同一事务中保存整副牌；重复或并发发牌返回同一次结果，不再次随机。

公共快照包含阶段、配置、准备状态、身份提交总人数和统一校验状态，绝不包含真实身份、按座位提交角色或角色统计。房主与其他玩家收到相同公共投影。

私人身份接口通过会话查找本人，拒绝通过请求参数指定另一个成员或座位。未占座成员没有身份；房主管理权不能扩大私人读取或提交权限。私人响应 `Cache-Control: no-store`，身份不进入 localStorage、公共 Socket.IO 广播、日志或 URL。

实体录入在开局前可由本人修正。未收齐显示统一等待提示；收齐且不匹配时全员看到同一句“角色数量不匹配，请各自检查身份”，不指出错误玩家、不展示缺失或多出的角色。重新提交立即重新校验；不能因已经匹配而提前禁止其他人的修正，最终锁定仅发生于开局事务。

刷新、重连读取服务器最新阶段、本人身份和确认状态，不创建新成员或重新发牌。身份默认隐藏，玩家主动查看；切 App / 页面隐藏立即遮罩。私人界面动作发生前重新校验阶段；客户端不能靠旧快照绕过身份锁定。

## 后续引擎边界

领域层保存板子版本和两维配置，为后续自动阶段、个人记录与房主官方事实分开建模。自动结算不被个人记录覆盖。本轮不提前创建没有实际内容的复盘、记录或胜负结果。

后续引擎必须分开内部死亡与公开死亡，支持批量夜间结算、白天逐死者判胜、终局优先、死亡队列插入、技能与遗言一次性处理、普通自爆指刀资格及吞毒排除。明确保留 12 人白痴正常死亡、180/60/30/30 秒和 10 秒间隔、统一死亡技能询问、猎人线下目标录入等规则。

首夜胜负时点、吞毒完整事件顺序、手动切回自动仍为 unresolved，不提供猜测分支；本轮准备与发牌不依赖这三个答案。

## 手机体验与验证

保留圆角卡片，主按钮深灰，蓝色只用于选择状态。手机大厅显示紧凑板子及角色数量；辅助文字在浅色背景上达到至少 4.5:1 对比度，输入字号至少 16px，触控目标至少 44px，适配安全区域。身份内容默认收起。

验证覆盖：独立 cookie / 浏览器上下文入房与同步、抢座、单人单座及换座原子性；前导零和有效号码唯一；四种配置；不足 12 人、未准备、房主未占座、非房主控制被拒；洗牌数量正确、重复请求和服务重启不重发；私密接口越权与公共消息泄密；实体数量错误统一提示与修正、锁定后不可修改；刷新和断线重连。

浏览器测试明确区分 Chrome 手机尺寸模拟、WebKit 模拟（环境可用时）及真实 iPhone。本机自动测试不能替代真机键盘、App 切换和常亮验收。最后报告实际命令、结果、访问方法、未测项目与后续任务。
