# 暂停、临时房主与重连交付（2026-10-10）

## 实现

- 房主或存活临时房主二次确认暂停，服务器冻结原阶段、剩余时间、技能、投票、测试推进和阶段切换。暂停次数和时长不限。
- 二次确认恢复后，全员共同准备 5 秒；倒计时结束再恢复原剩余时间。重复 / 过期提交不能重置倒计时，暂停与恢复准备均可跨服务重启。
- 原房主死亡后仍能管理公开流程。原房主可授权 / 收回一名存活临时房主；临时房主死亡后失去权限，不能转授、查看他人身份或代用夜间技能。
- 连接按服务器验证过的成员及其全部 Socket 统计。重复订阅或关闭一个标签不会造成假离线，最后一个连接断开才记离线。普通断线不暂停。
- 尚未提交的存活神职可获每人每局一次、最多 15 秒宽限；已重连时仅补当前阶段实际失去的操作时间。跨阶段不带入前一阶段时间；暂停 / 5 秒准备不计入损失；尚未重连最多等待 15 秒。狼人仍为严格 180 秒，不重新指定确认者。
- 公共界面只显示统一“连接异常”，不显示受影响座位、角色或宽限次数。临时管理权限不改变身份归属。
- 暂停期间可二次确认批量保存未来投票时长和票型公开程度。已进入的投票设置保持本轮默认，下一次设置才应用新值；当前票型及计时不变。
- 手机新增紧凑“管理”入口；暂停遮罩隐藏私人技能并保留首页导航，恢复显示共享倒计时。正常对局仍使用一个手机屏幕，管理设置使用弹层。

## 验证

- **119 / 119 服务端测试通过**（`npm test`）。其中本轮增加 12 个持久化 / 规则控制测试和 1 个独立 HTTP / Socket 组合测试。
- **20 / 20 Chrome 浏览器测试通过**（`npm run test:e2e`），含本轮 2 个新场景：独立客户端暂停 / 临时授权 / 刷新 / 5 秒恢复；暂停期间二次确认保存未来设置，下一轮才生效。320×568、390×844、430×932 的主游戏区不滚动，管理按钮在视口内。
- TypeScript、生产构建（`npm run build`）与 `git diff --check` 通过。
- 最终浏览器回归曾发现新测试夹具在初始会话完成前直接请求建房，返回 401；通过等待页面会话完成后再请求修正，完整重跑 20 项通过。产品入口本就等待初始化。

新增验证包含：独立 Socket / HTTP 客户端同步；最后连接离线；暂停中的技能、投票、阶段切换拒绝；冻结时私人接口不返回技能信息；5 秒准备期间拒绝操作；临时房主死亡 / 撤权、不能代用技能；原房主死亡后仍管理；按秒补偿与 15 秒上限；一次宽限跨重启和后续夜晚保持；已提交查验无额外宽限；狼人截止不延长；恢复边界先收到 Socket 的竞态；未来设置当前 / 下轮隔离；旧持久状态缺少默认字段的兼容。

独立审查发现并修正了跨阶段重连丢失当前阶段时间、暂停清空既有损失、Socket 在恢复边界先于定时器到达、旧暂停配置缺字段四个边界问题。开发者另补充当前投票设置默认值冻结验证。所有修复均先复现失败，再验证通过。

## 验证边界和下一步

浏览器验证为独立 Chrome 上下文和手机尺寸模拟，不是实体多手机或真实 iPhone Safari。尚未验收 Safari 动态地址栏、安全区、字体放大、锁屏 / 切后台后的真实网络行为、常亮及复杂网络延迟。部分规则使用测试时钟，未逐次等待全部最长时长。
