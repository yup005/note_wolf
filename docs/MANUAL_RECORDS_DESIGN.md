# 独立手动记录与多版本复盘

以详细需求 V1 第八章、第九章为基线，沿用用户已确认的手机优先、参赛房主、游客游玩与收藏。保留现有自动复盘。

- 每位参赛房主 / 已登录有效 VIP 拥有一份独立私密草稿。死亡（座位、轮次、夜/昼、可选死因）、警徽、放逐、个人票型、推理均由记录者录入；缺失字段明确“未记录”。个人草稿不进入广播或管理员公开房间响应。
- 纯手动从准备配置启动，或房主确认后从自动单向切换。保留自动历史与锁定身份，停止全部自动倒计时和技能入口。只导入已经公开的死讯，不提前公开待结算夜间死亡。暂不开放切回自动（M-01）。
- 房主明确提交官方死讯后，服务器按 12 人预女猎白屠边判胜；个人草稿不会改变官方结果。未结束时不把个人胜负计算返回为身份探测接口。VIP 在纯手动中可提交草稿事实的结束申请，个人推理不随申请共享；房主单独审阅事实，采纳保留房主原推理；拒绝后继续，采纳以房主明确确认的记录为官方版本。无房主响应保持待确认（H-01）。
- 正式结束后房主可继续修正官方记录并重新计算胜负，保留每次官方提交；完整官方修订仅房主可见，参局玩家只看主动发布的历史，避免未发布推理或撤回正文被绕过读取。若更正后没有达成胜负，显示“未达成胜负”，保留正式结束状态和身份公开状态，不自动重启对局。
- 赛后作者主动发布草稿形成不可变历史版本，随后编辑不会影响已发布内容。仅作者能撤回 / 再发布；参局玩家可查看历史与收藏。收藏关联帖子，跟随主动发布的最新版本；撤回后入口保留而正文不可读。个人版本不被官方修改覆盖。
- 记录和参赛访问名单独立持久化，房间删除不删除已发布帖子和收藏。游客登录关联记录、参赛访问名单与收藏。沿用旧收藏，新增版本收藏入口。
- 最小 VIP 权限由已有唯一管理员开通 / 取消，永久或到期时间；不包含支付、对外分享、评论。服务器实时验证资格，房主不会因此成为 VIP。
- 主游戏保留紧凑“记录”入口；纯手动主屏为 12 座位 + 官方状态 + 记录操作，适配手机一屏。详细编辑及历史查看放在独立弹窗。

死因默认提供狼刀、毒杀、放逐、猎人射杀、自爆、未记录，属于事实备注，不驱动自动技能 / 遗言 / 吞毒结算；H-02 的复杂机制继续待定。所有输入严格校验、带草稿修订号，避免多设备或重复提交覆盖。
